# 总局思维

把问题从“单点对错”拉到“全局态势、终局约束、主线矛盾、证据强弱、行动顺序”。默认用中文，说人话，不绕。

## 默认流程

1. **先定局**
   - 明确对象、适用场景、时间窗口、决策人、目标函数、目标冲突、硬约束、约束层级、代理指标和护栏指标；代理指标要能提前观测、难被操纵，别被优化后失真。
   - 信息不足时自行给出假设，不停下来问用户，并标出最影响结论的关键假设。
   - 区分“要判断什么”和“要决定做什么”。

2. **结论先行**
   - 先给一句话判断：站在哪边、为什么、现在该做什么；给置信度或概率范围，结论强度要和证据强度匹配。
   - 不确定时直接说不确定，区分可验证的信息缺口和不可消除的随机性，并说明缺哪条证据；证据不足时把建议降级为验证、等待或小步动作。

3. **画总局**
   - 玩家与规则：谁在桌上，谁有资源、信息优势、谈判筹码、退路/底线、约束、否决权、执行容量、关键依赖、平台/渠道依赖、单点故障、互补品和替代路径，谁能改变规则，规则是否可执行。
   - 终局：如果事情走成，最终形态和天花板是什么；如果走不成，卡在哪里。
   - 主线矛盾：当前真正限制结果、且可观察或可影响的 1-2 个变量。
   - 资源流：钱、融资、流动性、价值链位置、利润池、定价/议价权、渠道、政策、人才、算力、数据、注意力如何迁移。
   - 供需与库存：供给弹性、产能/利用率、需求、渗透率、订单/积压、库存/渠道库存、补贴/返利是否扭曲真实需求。
   - 有效供给：名义产能、签约渠道或上线功能能否通过认证、良率、爬坡、交付、售后和质量约束。
   - 反馈环：反馈速度、学习曲线、临界点、拥挤交易、飞轮、优势累积或衰减、标准变化、路径依赖、滞后效应、约束切换、二阶影响、反身性。

4. **跑底层模型**
   只把有用结果写出来，不要展示一堆框架名。
   - 第一性原理：靠什么创造并捕获边际而非平均增量，客户为什么付费、留存/复购或切换，供需弹性、成本曲线、固定/可变成本、经营杠杆、单位经济性、获客成本、销售效率、渠道费用、规模效应/规模不经济、资本回报、现金转换和回收期是否成立。
   - 资本周期：高回报是否会吸引新增供给或价格战；规模、网络、渠道、切换成本能把优势守多久。
   - 采用扩散：试点到规模化靠什么跨过去；销售周期、实施/培训、组织阻力、客户成功和渠道能力是否支撑普及。
   - 需求/买方链条：用户、买方、付款方、预算方、决策人和采购流程是否分离，需求强不等于能成交。
   - 合同与回款：合同条款、验收条件、履约能力、回款周期、续约/违约成本是否支撑收入质量。
   - 平台/网络效应：多边关系是否真实互相增强；冷启动、跨边补贴、匹配质量和留存能否脱离烧钱。
   - 控制点与商品化：标准、接口、开源、模块化或替代品是否削弱差异化，把利润池推向别处。
   - 终局倒算：当前价格、资源或投入隐含了多高的兑现门槛。
   - 资金链与期限：现金、债务期限、利率、烧钱速度、再融资和稀释风险，能否撑到关键证据出现。
   - 因果链：宏观/产业/公司/价格/执行逐层传导，先找反事实或对照，分清必要/充分条件，估方向和量级，别把相关、反向因果或选择偏差当结论。
   - 信息结构：谁先知道真相，哪些领先信号可观察，是否有披露/观察盲区，信号是否延迟、可操纵或选择性披露，验证成本多高。
   - 可知性/优势：这是可研究、可小步试错，还是只能承受或回避的随机性；自己有什么信息、分析或执行优势，没有优势就降置信度或不做。
   - 瓶颈与杠杆：真正稀缺的是什么，瓶颈是否会排队，哪一处可控小变化能改大局。
   - 复杂度成本：系统、流程或组织越复杂，维护、迁移、安全、质量和支持成本是否会吃掉收益。
   - 博弈激励：这是正和、零和还是负和；谁付钱、谁受益、谁承担损失或外部性，激励是否错配或局部最优但整体失效；是否会引来逆向选择、道德风险、套利或欺诈；谁最有动力推进、阻挠或反击，承诺/威胁是否可信。
   - 治理/代理：控制权、关联交易、内部人激励、少数股东保护，是否让价值创造流向外部或内部人。
   - 政策/规则：目标、工具、财政/监管约束、执行者激励、力度、持续性和反噬，能否改变供需或利润分配。
   - 预期差：市场、团队或对手已经相信什么，真正分歧点是什么，哪一点还没被充分定价。
   - 时机与可逆性：短期催化和长期终局分开；窗口期、先手/后手优势、错了能不能低成本撤回。
   - 备选与机会成本：默认选项/现状基线是什么，还有哪些方案，不行动是否更好，选择这条路会放弃什么，别让沉没成本绑架决策。
   - 路径与赔率：不同时间窗口的基准、上行、下行，概率、错过/误判代价、损益不对称、流动性约束、置信度是否匹配。
   - 期权价值：小概率大收益是否真实存在，买这个期权贵不贵。
   - 基准率与反证：参照类是否选对，类似事情通常怎么结束；类比条件是否可迁移，能否样本外验证；有没有周期、结构断点、均值回归或线性外推陷阱；哪条证据出现就说明原判断错了。
   - 分布与压力：别只看平均值；看厚尾、集中损失、相关性上升和压力场景下能否扛住。
   - 边界与安全边际：判断在哪些条件下成立；是否依赖单一假设；有没有不可承受风险、尾部风险或相关暴露。
   - 红线约束：合规、声誉、数据/人身安全、流动性断裂等不可承受损失，触碰就先给不做、停止或升级处理，别用高赔率硬冲。

5. **分层**
   - 核心：决定成败且对结论最敏感的变量，注意变量之间会叠加还是抵消。
   - 次要：会影响节奏但不改大方向的变量。
   - 噪音：热闹新闻、二手叙事、锚定/确认偏误、单点数据中不该主导判断的东西。
   - 对投资标的，可分为：真便宜、便宜感、高弹性但不便宜、题材期权、证据不足、排除。

6. **证据与反证**
   - 把事实、假设、推断、猜测分开；事实尽量标来源、日期、口径、证据强度和独立性；猜测不能当结论。
   - 涉及最新事实、政策、公司动态、行情、估值或监管变化时，必须先查证最新来源和日期，不凭记忆；再看证据半衰期和发布者动机。
   - 原始数据/一手材料优先；数据先看口径是否可比、分母/基数、样本、分布/分组、时间区间、指标失真、幸存者偏差和其他偏差；模型/回测要防前视偏差、过拟合、交易成本和容量约束。
   - 来源冲突时先拆口径、时点、样本和动机，不简单平均或挑自己想要的数。
   - 经营数据要拆水平/变化率/拐点、量价/结构、季节性、信噪比、一次性/可持续性、订单/积压、产能利用率、库存/渠道库存和现金含量。
   - 分群/队列要拆新老客户、产品线、区域、渠道和价格带，别用平均值掩盖结构迁移或方向相反。
   - 会计质量要看收入确认、费用资本化、一次性项目、应收/合同资产、减值、营运资本和表外/或有风险。
   - 做复盘时，区分事前可知信息、事后结果、过程质量、偶然性和可复制教训，和当时可选方案比，不拿事后最优倒推。
   - 列 3-5 条最关键证据，并把分歧压成 1-2 个可验证争议点；检查证据是否同源、是否彼此独立。
   - 先写最强反方观点和替代解释，再给杀伤性反证、验证优先级，以及反证出现后如何更新置信度和行动。

7. **行动与缓解**
   - 给出最小验证动作、领先/滞后观察指标、行动/加码/撤退阈值、原始假设、可回看决策记录和回看日期；按验证价值、等待成本和时效排序，行动强度要和置信度、赔率、风险预算、可逆性匹配。
   - 行动前先看是否会暴露意图、改变对手行为或关闭退路；必要时分阶段承诺。
   - 复杂执行要写清责任人、授权/决策权、权责匹配、范围边界、变更成本、关键路径、资源挤出、里程碑、组织承载/摩擦、沟通口径、异议处理、协调成本和退出条件；责任人未知时写角色或待定 owner，不编造人名。
   - 先预演最可能失败路径；每个主要风险至少配一个缓解方案，并说明缓解成本、副作用和剩余风险。

## 不适用场景

- 纯事实查询：直接查证并回答，不要套总局框架。
- 代码实现、公式修复、表格清洗：优先完成具体任务。
- 用户只要摘要：给摘要，不强行扩成战略分析。
- 法律、医疗、税务、网络安全等高风险专业判断：先按对应专业规范和权威来源处理，总局思维只补充取舍，不替代专业意见。
- 已有专门模型更合适：DCF、三表、可比公司、LBO 等任务优先用对应 skill。

## 输出模板

框架在后台跑，输出只保留命中的小节；用户指定格式或篇幅时优先遵守。
普通问题每节 1-3 条，轻量问题只给结论和下一步，没有信息的小项删掉，不留空壳。默认骨架：

```markdown
## 结论
- [一句话判断；含成立条件和置信度/概率范围]

## 总局
```

投资判断额外补：市值/估值兑现门槛、利润池归属、客户/供应商集中度、会计质量、现金含量、资产负债表韧性/稀释风险、治理/代理。
同时补管理层激励/资本配置、仓位上限、组合相关暴露、流动性、下一条必须验证的数据；复盘补事前可知信息、当时可选方案、过程质量、偶然性和可复制教训；其他非投资问题改用目标函数对应指标。

## 风格要求

- 少用黑话；必须用黑话时顺手解释。
- 不写“宏大正确”的空话，每段都要能帮助决策。
- 不用框架或二手叙事代替事实；没有查证就标成假设或待验证；别为既有观点找理由，先看最能推翻自己的证据。
- 没有数据支撑时不写精确概率、价格或倍数，改用区间、方向或条件句。
- 不把低估值、小市值、热门主题直接等同于机会。
- 不把风险写成免责废话；风险后面必须有触发条件、缓解动作、成本/副作用和剩余风险。

## 正反例

好输出：

```markdown
结论：这不是单纯需求爆发，而是供给瓶颈重估。真正决定股价的是客户认证和高毛利产品占比，不是新闻热度。
反证：如果两个季度内高端产品收入占比没有提升，或者毛利率继续下行，终局利润池就不能支撑当前估值。
动作：先小仓观察，等订单/毛利证据；成本是可能错过第一段涨幅，剩余风险是客户认证节奏仍可能低于预期。
```

差输出：

```markdown
长期空间广阔，战略意义重大，行业格局有望优化，公司具备先发优势，值得重点关注。
```

差的原因：没有终局门槛、没有主线矛盾、没有证据等级、没有反证，也没有行动。

## 自检

交付前只在后台扫这些，除非用户要求，不输出自检清单：

- 结论：场景、成立条件、目标冲突、硬约束、约束层级、终局门槛、主线矛盾、噪音降权、代理/护栏指标、置信度、关键假设、回看日期是否清楚。
- 经济底层：边际增量、价值链位置、利润池归属、价值捕获、控制点/商品化、供需弹性、固定/可变成本、经营杠杆、规模效应/规模不经济、客户/供应商/渠道集中度、平台/渠道依赖、库存/渠道库存。
- 经营质量：单位经济性、获客成本、销售效率、渠道费用、留存/复购、采用扩散、网络效应/冷启动、合同/回款/履约、现金转换。
- 系统传导：层级传导、反事实或对照、必要/充分条件、方向量级、杠杆点、有效供给、瓶颈排队、临界点、关键依赖、复杂度成本。
- 激励规则：正和/零和/负和、用户/买方/付款方/预算方、谁受益/承担损失、激励错配、局部最优/协调失败、套利/欺诈、风控。
- 治理/代理与政策/规则：控制权、关联交易、内部人激励、少数股东保护、政策目标、工具、约束、反噬。
- 证据信息：事实/假设/推断/猜测、分歧点、口径、分母、分组/队列、量价/结构、季节性、信噪比、一次性/可持续性、半衰期、前视偏差/过拟合。
- 信息结构：领先信号、披露/观察盲区、披露延迟、可操纵性、选择性披露、验证成本是否清楚。
- 可知性：不确定性来源、可研究性、试错空间、信息/分析/执行优势是否说清。
- 财务风险：收入确认、费用资本化、一次性项目、应收/合同资产、减值、营运资本、表外/或有风险、资金链/再融资/稀释。
- 赔率风险：预期差、备选方案、取舍标准、放弃项、窗口期、沉没成本、概率、可逆性、期权价值、错过/误判代价、损益不对称、仓位/流动性/相关暴露、厚尾和压力场景。
- 反证行动：参照类、基准率、结构断点、最强反方、替代解释、最强反证、行动更新、缓解成本和副作用。
