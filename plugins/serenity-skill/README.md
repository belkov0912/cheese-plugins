# serenity-skill

Serenity 式供应链「卡点」研究:从市场叙事出发,走通真实产业链,找到稀缺环节,
用硬证据验证,再排出最值得深挖的研究优先级。

来自 [muxuuu/serenity-skill](https://github.com/muxuuu/serenity-skill),MIT。仅做
研究支持,不涉及交易执行。

## 技能

- **`serenity-skill`** — 把投资 Agent 变成供应链卡点猎手:有据可查的投研、产业链/
  价值链映射、A股/港股/美股筛选、thesis 压力测试。触发词如「用 Serenity 的方式看」
  「产业链/供应链/卡点/瓶颈」「哪个最值得研究」「challenge this thesis」。

## 何时用

研究一个市场主题、想找出被忽视的稀缺环节、或想给已有 thesis 做压力测试时。
