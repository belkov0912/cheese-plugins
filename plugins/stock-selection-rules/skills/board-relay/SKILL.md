# 二三板接力 · 收盘后离线筛选

方法出处：Obsidian `03-Trading/交易模式/资料摘录/两个小馒头.md`。用户的理解（以此为准）：

- 龙头 = 前一日板块批量涨停后，第二天**最快封二板**的那只；所以收盘后只能筛出"该盯谁"，买点在次日盘中。
- 买入后第二天溢价 ≥3% 才算符合预期，不到就走。
- 不抠字眼："不隔夜"只是形容不及预期立刻割；炸板风险靠入场前层层过滤规避。

## 怎么跑

```bash
S="${CLAUDE_PLUGIN_ROOT}/skills/board-relay/scripts/run_board_relay.sh"   # 没有该变量时用本 SKILL.md 旁的 scripts/
"$S" screen                          # 最近完整交易日（北京时间 15:30 后算当天）
"$S" screen --date 2026-11-02 --top 5
"$S" screen --json                   # 机器可读
"$S" backtest --days 7 --top 3       # 回测：最近 7 个交易日每天 top3 的次日表现
"$S"                                 # 不带参数 = 离线自检
```

- 依赖 `akshare`、`pandas`、`requests`；wrapper 会自动找装好依赖的 Python（可用 `BOARD_RELAY_PYTHON` 指定）。**不依赖 r0-data 本地日K仓**。
- 联网：同花顺涨停池/热点板块 + 东方财富涨停池、日K、公告、解禁。一次筛选约 20–60 秒；回测 7 天约几分钟，用后台跑。
- 缓存在 `$R0_DATA_DIR/board_relay/`（缺省 `~/.r0-data/board_relay`），只缓存已定稿的盘后数据。
- 盘后数据 15:30 后才定稿：用户 17:00 跑就是当天；15:30 前跑默认上一交易日，要当天就等收盘后再跑。

可调参数：`--top`、`--min-theme`（共振家数，默认 3）、`--min-block-chg`（热点板块涨幅，默认 2%）、`--max-float-cap`（流通市值上限，默认 200 亿）、`--min-first-to-mult`（首板换手倍数下限：当日换手 ÷ 自身前 20 日换手中位数，默认 1.5）、`--include-688`、`--no-notice`（跳过公告排雷）。

## 规则（按方法顺序）

| 步骤 | 规则 |
|---|---|
| 范围 | 只看当天涨停：1 连板 → 次日**二板候选**；2 连板 → 次日**三板候选**；≥3 连板（次日 4 板+）只报高度，不参与 |
| 定题材 | 题材以每只票自己的**涨停原因**为证据：同题材当天涨停 ≥3 家才算共振。同花顺热点板块（板块涨幅 ≥2%）只用来把相关标签并成一条主线并命名：公司系（华为/腾讯/阿里…）和"人工智能""数字经济""机器人概念"这类大而泛的概念不参与合并；一个标签要被簇里涨幅前 3 的某个板块覆盖过半才并进主线，否则自成题材（如"金融科技""羊字辈"）。核心标签互为子串的（机器人/人形机器人）并成一条。业绩、重组、国资、超跌这类个股事件标签不算题材 |
| 看盘口 | 剔除一字板（没换手）、尾盘偷袭（首封 ≥14:30）、烂板（开板 ≥3 次，或开板后 ≥60 分钟才回封） |
| 卡量能 | 首板：换手倍数（当日换手 ÷ 自身前 20 日换手中位数）≥1.5 且量比（当日量/前 5 日均量）≥1，缩量首板不做。不用绝对换手：大盘子 1.5% 可能已是平时的 4 倍，小盘子 5% 可能还不如平时。上市不满约 10 个交易日的次新算不出倍数，只卡量比；二板：较首板日缩量优先（打分项） |
| 排雷 | ST/退市、北交所、科创板（默认）、流通市值 >200 亿；近 30 天公告里有减持（非"实施完毕/结果"）、立案/处罚/问询/监管/警示、预亏/预减、退市风险；未来 30 天解禁 ≥流通市值 1%（解禁公告本身只标注，股权激励解除限售多半很小） |

公告只看筛选日及以前发布的，回测同样截断，杜绝后视。

## 打分（满分 100，决定 top N）

题材 30（同题材涨停家数：≥20→30，≥10→25，≥6→20，≥4→15，3→10）＋ 封板时间 20（≤9:35→20，≤10:00→16，≤10:30→11，≤11:30→6，≤14:00→2）＋ 不开板 10（没开→10，开 1 次且 15 分钟内回封→5）＋ 量能 20（首板换手倍数 ≥4→20，≥3→16，≥2→10，≥1.5→5，次新退回量比档；二板较首板 ≤0.8→20，≤1→16，≤1.3→10，≤2→5）＋ 题材内先手 10（候选里首封最早→10，第 2–3→5）＋ 市值 10（流通 ≤50 亿→10，≤100→7，≤150→4）。

## 怎么回报

结论先行，按这个顺序：

1. 情绪一句话：涨停/跌停/封板率、上一交易日涨停今日表现、连板梯队和最高板（背景，不是硬门槛）。
2. 主线题材：前 2–3 个题材和涨停家数；没有达标题材就直说"没有共振，按方法空仓"。
3. top N 表：代码名称、次日是二板还是三板、题材、首封/末封、开板、量能、换手、流通、分数、**次日涨停价**、**+3% 溢价线**（买入后第二天开盘溢价不到它就走）。
4. 其余候选按题材分组列出，点出同题材里谁最值得盯。
5. 排除统计里值得一提的：利空命中的票和原因、高标高度。
6. 收尾提醒：这是观察名单不是买入指令；次日只打盘中确认的那只（同题材最快封板、10 点前封死、封后不开）；看不懂、没共振就空仓。

## 存档

- 每次筛选的候选自动存到 `$R0_DATA_DIR/board_relay/picks/YYYYMMDD.csv`（数据缓存，不是笔记）。
- 用户明确说"存档/记到笔记"时，加 `--md-out` 写到 vault 的 `03-Trading/每日涨停板/YYYY-MM-DD/二三板接力筛选.md`（vault 的 AGENTS.md 规定的位置）。不主动写笔记。

## 回测

`backtest --days N --top K --success S`：取最近 N 个"次日已收盘"的交易日，每天用当天数据跑同一套 `screen()` 取 topK，看次日相对筛选日收盘的开盘/最高/收盘涨幅。**次日收盘涨幅 ≥ S%（默认 3）算成功**，另报盘中最高触及率、次日涨停率，以及"全部候选""全部涨停股"两个对照组。几天的样本只能看形状，不能当胜率；不要为了迎合几天的回测去改阈值。

## 定时运行（用户要求才装）

想每个交易日 17:00 自动跑，告诉用户可以加一条 cron/launchd：`0 17 * * 1-5 <插件根>/skills/board-relay/scripts/run_board_relay.sh screen --md-out <vault>/03-Trading/每日涨停板/$(date +\%F)/二三板接力筛选.md`。只给命令和说明，用户明确要求才替他装。

## 数据口径与缺口

- 东方财富涨停池只保留最近几周：更早的日期没有开板次数和连板数，开板按同花顺"回封"标记加首封到末封的间隔判断，连板数按同花顺"N天M板"逐日回溯。输出头部会写明用了哪些源。
- 同花顺热点板块每天只给涨停家数前 20 的概念；靠涨停原因标签补足小题材。
- 日K为东财前复权价、原始成交量；次日涨停价按筛选日实际收盘价计算（主板 10%，创业板 300/301/302、科创板 20%）。
- 公告排雷看标题关键词，可能漏掉标题不直白的利空；命中的强利空直接剔除，弱提示（风险提示、减值、冻结质押）只标注。

## 边界

- 只做收盘后的观察名单；盘中打不打、什么时候打，看用户的实时盘口。
- 不下单、不荐股、不给仓位。
- 单票形态（R0/R7/R9）、主线行业强度（R1）走对应 skill；本 skill 只做二三板接力筛选。
