# R7 · 试盘后回踩即时查

回答一个很窄的问题：**这只票最近 20 个交易日里，有没有出现「相对自身明显放量试盘 → 最近 5 日缩量回踩」的形态？** 输出 1-5 分。

R7 是观察信号，不是买点。它找的是「资金试过盘、洗过盘、还没真正再次转强」的票；没有回踩、直接主升的票交给 R0 扳机看，冲高后放量砸回平台的票不算好 R7。

## 脚本与数据在哪

- **脚本**：本插件根目录的 `scripts/r7.py`（从本 SKILL.md 位置上两级即插件根；也可用 `${CLAUDE_PLUGIN_ROOT}/scripts`）。
- **数据**：用户本地，`$R0_DATA_DIR`（缺省 `~/.r0-data`），和 r0-breakout 共用。首次使用先走 **r0-data skill** 建仓；没建仓时单票查询会自动联网现抓，但 `--today` 全市场名单必须有本地仓。
- 依赖：同 r0-breakout，`python3` + `akshare`、`pandas`、`pyarrow`、`yaml`。缺包时先走 r0-data skill 的依赖自检和安装流程。

## 铁律

- **R7 不是买点。** R7 高只说明「曾经试过盘，最近在缩量回踩」，真正动手仍要等 R0 放量强阳突破，或用户自己的交易系统给出再次转强信号。
- **不要把 R7 当选股器。** 它只能缩小观察名单，必须和主线、基本面候选池、R0 扳机交叉看。
- **只读、不写笔记。** R7 每天在变，不往用户笔记里写。用户明确说「存档/记下来」才写。
- 不下单、不荐股、不碰钱。
- 数字口径：后复权(hfq)日K，盘中也只按上一根完整收盘K线算。

## 怎么跑

```bash
cd <插件根>/scripts
python3 r7.py 景旺电子 603228 sz300476     # 逐票报 R7（名称或代码混着给都行）
python3 r7.py --today                        # 扫本地仓：R7≥4 的试盘回踩名单，默认排除 bj* / sh688*
python3 r7.py --today --min 5                # 只看 R7=5
python3 r7.py --today --include-bj688        # 包含北交所和科创板 688
python3 r7.py                                # 无参 = 自检
```

- 名称解析靠本地 `universe.csv`（r0-data 建仓时保存）；解析不出唯一代码时，让用户给 6 位代码，别猜。
- `--today` 默认排除 `bj*` 和 `sh688*`；用户明确要北交所/科创板 688 时加 `--include-bj688`。单票查询不受这个默认过滤影响。
- 数据<50根返回「数据不足」，如实转告。

## R7 怎么打分

R7 以个股自身近 60 日水平为基准，判断试盘日是否出现明显的相对放量异动。

**试盘日成立**：

```text
单日涨幅 >= 7%
且满足以下任一：
1. 5日量比 >= 1.8
2. 当日换手 >= 近60日换手中位数的 2倍
3. 当日成交额 >= 近60日成交额中位数的 2倍
4. 当日近似涨停/20cm强阳，且突破前5日高点
```

**5日量比** = `试盘日成交量 / 试盘日前5个交易日平均成交量`，不包含试盘日自己。

**回踩成立**：最近 5 日平均成交量 / 试盘日前后活跃段平均成交量 ≤ 0.8，并且最近 5 日低点没有明显跌破试盘前平台。

| R7 | 含义 |
|---|---|
| 5 | 有试盘 + 缩量回踩 + 结构未明显跌破，等待再次转强 |
| 4 | 有试盘 + 回踩量能收缩，但结构稍弱或缩量没到最优 |
| 3 | 有试盘但尚未完成缩量回踩，或回踩失败 |
| 2 | 只有轻微活跃，没有完整试盘回踩结构 |
| 1 | 无试盘、无相对放量、无回踩结构 |

CLI 每行形如：

```text
R7=5  sh603228 景旺电子  R7=5 试盘2026-06-18 涨8.4% 换手4.2% 量比5=2.1 相对换手2.3x 相对额2.8x 回踩量比0.62 结构未破｜结构线(屏幕价,复权因子1.41): 平台36.97 / 容忍35.86 / 最近收36.10
```

**结构线三个价的含义**（回报时讲清）：
- **平台** = 试盘日之前 5 个交易日的最低收盘价——回踩不能有效跌穿的台子；
- **容忍** = 平台再让 3%——收盘跌破这里才判"结构跌破/回踩失败"；
- **最近收** = 数据里最后一根收盘，方便和前两条比。
- 单票模式会联网拉一次原始价，把这三个价换算成**屏幕价**（行情软件的除权价）；拿不到原始价时标注"后复权价"原样打出，此时绝对数字和行情软件对不上（差一个复权因子），但比例关系不变。`--today` 名单不做换算（每只都要一次网络请求）。

## 怎么回报

结论先行，别铺陈：

```text
景旺 R7=5，属于「试盘后缩量回踩」。
证据：6月18日涨8.4%，5日量比2.1，换手是60日中位的2.3倍；最近5日量能缩到试盘活跃段的0.62倍，结构没明显跌破。
但 R7 不是买点，只说明资金试过盘、现在在洗；真正动手还要等 R0 或再次转强。
```

多只：逐行报，最后可汇总一行如 `景旺 R7=3 · 胜宏 R7=5 · 利安隆 R7=1`。

## --today 名单怎么用

`--today` 列的是「最近 20 日出现过试盘并完成或接近完成回踩」的观察名单，不是今天可以买的名单。回报时要点破：R7 高的票要再交叉用户自己的基本面候选池和 R0 扳机。

## 边界

- R0 放量强阳突破 → 用 r0-breakout。
- 下载、更新、检查本地行情仓 → 用 r0-data。
- 基本面建池、估值、消息面、下单建议 → 不是本 skill。
- 本 skill 只做 R7 这一条试盘回踩形态，不输出综合分。
