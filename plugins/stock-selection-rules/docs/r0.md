# R0 启动扳机

R0 回答一个窄问题：**最近 5 个交易日（判定窗 J）里，有没有出现「放量强阳突破」这根启动确认K线？出现过的话成色多高？**

它是介入扳机，不是选股器。R0 只回答「候选池里已看好的票，该不该扣扳机」；没有基本面候选池就单看 R0 = 追涨。满分票八成以上照样不涨（见回测），它给的是赔率改善，不是胜率承诺。

私有扫描器仓库提供多规则回测（`run.py --mode backtest`，R0-R8 与综合分一起测）；本插件的 `backtest_r0.py` 专门验证 R0，结果口径见下文。

## 怎么查

```bash
cd plugins/stock-selection-rules/scripts

python3 r0.py 景旺电子 603228 sz300476    # 名称或代码混着给都行
python3 r0.py --today                       # 最近5个交易日内扣过扳机（R0≥4）的名单
python3 r0.py --today --min 5
python3 r0.py --today --include-bj688       # 包含北交所和科创板688（默认排除）
python3 r0.py                               # 无参 = 自检
```

- `--today` 的语义是「判定窗（最近 5 个交易日）里出现过扳机K线」，不是"仅今天涨的票"。
- 数据用 `$R0_DATA_DIR`，缺省 `~/.r0-data`，K线为后复权(hfq)；输出全是比例（涨幅/量比/换手），没有绝对价，不存在复权换算问题。
- 仓里没有的票自动联网现抓（只取到上一收盘，带 15:05 北京时间保护）。

## 扳机是什么意思

38 只月涨 70%+ 翻倍股的研究发现：放量、强阳、突破这些教科书"启动信号"，**是确认日的同步信号，不是能提前埋伏的领先信号**——从启动基准日到首次涨满 20%，中位只有 6 个交易日，决定性催化几乎都在确认日当天或之后才暴露。

所以整套用法是两步：事前用基本面（主线/财报/市值那套）把全市场筛成候选池；候选池里的票**哪天出现这根确认K线，哪天才动手**。R0 就是把"这根线出现没有"做成 1-5 分。

代价也在研究里写明白了：等确认再买，相对启动基准往往已让出头部 10~20% 涨幅——要确定性就得让利，既要最低位又要确认信号是不可能三角。

## 打分公式

阈值在 `rules_config.yaml` 的 R0 段：

```yaml
R0:
  strong_pct: 0.07        # 强阳
  mid_pct: 0.05
  weak_pct: 0.04
  volratio: 1.4           # 5日量比门槛
  onechar_turnover: 0.02  # 换手<此值视为一字板/买不到，降一档
```

基础指标（`features.py`，对判定窗 J = 最近 5 根K线逐根算）：

```text
pct[i]       = close[i] / close[i-1] - 1
volratio5[i] = volume[i] / mean(volume[i-5 : i])     # 不含当日
breakN[i]    = close[i] > max(close[i-N : i])        # N = 5 / 10 / 20，收盘口径
turnover[i]  = 当日换手率（分数）
```

**逐根定档，取 J 窗内最强一根**（`score.py::score_R0`）：

```text
5 分 = pct≥7% 且 量比5>1.4 且 破5日高 且 兼破10日、20日高
4 分 = pct≥7% 且 量比5>1.4 且 破5日高（未同破10/20）
3 分 = (pct≥7% 且破5日高 但量比≤1.4) 或 (量比>1.4 且 5%≤pct<7% 且破5日高)
2 分 = (4%≤pct<7% 且量比>1.4，未破高) 或 (破5日高但 pct<5%)
1 分 = 都没有
一字板降档：当日换手 < 2% 且分数 > 1 → 降一档（买不到的信号不算可执行信号）
```

## 分数含义

| 分数 | 代码定义 | 白话 |
|---|---|---|
| R0=5 | 强阳 + 放量 + 同破 5/10/20 日高 | 满级确认：吃掉近一个月所有套牢盘 |
| R0=4 | 强阳 + 放量 + 只破 5 日高 | 强确认：刚脱离最近一周盘整 |
| R0=3 | 缺一条腿（没放量，或涨幅只有 5~7%） | 确认成色不足 |
| R0=2 | 放量中阳没破高，或破高但涨幅弱 | 有动静，不够格 |
| R0=1 | 无信号 | 判定窗内没扣扳机 |

阈值出处要分两类说：**7% / 量比 1.4 / 破 5 日高（最好兼破 10/20）来自 38 只翻倍股研究的定论**；1-5 分的次级分档（5%、4%、换手 2% 降档）是量化成评分卡时加的工程分档，没有独立统计依据，属可调参数。

回测里 R0=4 和 R0=5 的命中率几乎一样（θ=20% 都是 20%，θ=30% 都是 11%）——"兼破 10/20 日高"这层加码在已测窗口里没体现增量。更合理的读法：

```text
R0≥4：扳机扣了，值得按你的候选池对一下
R0=3：动了但没确认，等
R0=1/2：没信号
```

## 回测方法

```bash
cd plugins/stock-selection-rules/scripts
python3 backtest_r0.py                  # 全量约3-5分钟；默认排除 bj*/sh688*
python3 backtest_r0.py --include-bj688  # 全市场口径（对账扫描器用）
python3 backtest_r0.py --limit 50       # 冒烟
```

协议（`bt_common.py`，与 `backtest_r7.py` 完全一致）：

1. 读本地全A日K数据仓（hfq）。
2. 每只票沿历史每 15 个交易日取一个锚点（= 结果窗长度，结果窗互不重叠）。
3. 每个锚点只用 ≤锚点的K线算 R0（判定窗 = 锚点前 5 根，无未来函数）；锚点后 15 个交易日内最大收盘涨幅做结果标签。
4. θ 扫 20% / 30% / 50% 三档。
5. **对照全池，不只看赢家**：按 R0 分数分桶比命中率——把「涨过的票长什么样」(P(高分|已翻倍)) 纠正成「长这样的票会不会涨」(P(会涨|高分))，只统计赢家会踩幸存者偏差。
6. 每个窗口单独算 Spearman IC，看均值、更看符号稳定性（几个窗口为正）——稳定性才能排除"某段行情碰巧给的"。

**和 `docs/r7.md` 回测数字的可比性**：协议与默认票池（排除 `bj*/sh688*`）已完全一致；唯一残留差异是窗口数——R7 的试盘定义要回看 60 日相对量能，最早两个窗口取不到（12 窗 vs R0 的 14 窗），横比时以重叠的 12 个窗口为准更严谨。

## 2026-07-06 回测结论（插件版 backtest_r0.py）

口径：默认排除 `bj*/sh688*`，14 个不重叠窗口（2025-08 ~ 2026-06），合并 N=60990，数据截至 2026-07-06。

| 指标 | 数值 |
|---|---|
| 均值 IC | +0.09 |
| IC>0 窗口 | 13/14 |
| θ=20%：R0=5 命中 / 基础命中 | 19.6% / 10.2%（lift 1.92） |
| θ=30%：R0=5 命中 / 基础命中 | 10.6% / 4.8%（lift 2.23） |
| θ=50%：R0=5 命中 / 基础命中 | 3.8% / 1.3%（lift 2.83） |
| R0≥4 精度 / 赢家召回（θ=50%） | 3.4% / 17.3%（覆盖率 6.8%） |

对账：`--include-bj688` 全市场口径下均值 IC +0.08、13/14 窗为正（N=73003）——与扫描器 2026-07-02 首跑（+0.07、11/14，当时数据到 07-02）一致，插件版复现成立。

结论：

- R0 有真 edge，且跨行情稳定（13/14 窗口 IC 为正）；满分桶命中率约为基础的 2 倍，θ 越苛刻 lift 越高（θ=50% lift 2.83）。
- 但绝对命中率低：R0=5 的票在 θ=20% 下也只有两成会涨——**扳机给的是赔率改善，不是胜率**。
- 分档的真实形状是「1/2 vs 3+」：R0=3、4、5 的命中率彼此接近（θ=20% 为 18.2%/19.5%/19.6%），"兼破 10/20 日高"和"放量与否"的加码在已测窗口里增量很小；**R0≥3 就有信息，别把 5 分神化**。
- 召回只有 17%：很多票不走"放量突破"剧本，R0 会漏，不能当全量网（回踩型的交给 R7 观察）。
- 已知近似：合并分桶把同一票多窗口当独立样本（显著性被高估）；票池是今日在市票（轻微幸存者偏差）。R0 是纯量价规则，不受市值/财报前视影响，是九条规律里口径最干净的之一。
- 复现纪律：walk-forward——改阈值用历史窗口提假设、用之后新窗口检验，别在同一批数据上又调参又宣布变好。
