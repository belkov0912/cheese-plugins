# Comparable Company Analysis

生成可审计、可更新的可比公司 Excel，回答目标公司的经营质量和估值相对同行处于什么位置。

## 开始前

明确：

- 目标公司、估值日期和币种。
- 使用场景：投资、并购、董事会或快速对标。
- 用户指定的同行、模板和格式偏好。
- 关键问题：便宜、增长、效率、现金创造，还是综合比较。

用户模板优先；不要为了套默认格式重建已有结构。

## 数据源

优先使用可用的结构化金融数据源；其次使用监管文件、公司公告和可靠市场数据。网页聚合数据只作补充或交叉验证。

所有同行必须使用相同或可比的时间口径、币种和指标定义。每个硬编码输入添加来源批注，包含文件/系统、日期、位置和 URL。无法取得的数据标 `N/A`，不得静默估算。

## 同行选择

通常选择 5-10 家，按以下维度筛选并说明纳入/排除理由：

- 商业模式和收入来源。
- 客户、地域和监管环境。
- 规模、增长、利润率和资本强度。
- 生命周期及会计口径。

纯业务同行优先于规模相似但业务不同的公司。宁可保留少量高质量同行，也不要为数量加入不可比公司。

## 指标选择

先用 5 个左右经营指标和 3-5 个估值指标；只有决策需要时再增加。

### 通用经营指标

- 收入、收入增速。
- 毛利率、EBITDA 率。
- FCF、FCF 率或净利润率。

### 通用估值指标

- 总市值、企业价值。
- EV/Revenue、EV/EBITDA、P/E。
- 适用时加入 FCF Yield、P/B、PEG 或股息率。

### 行业补充

- SaaS：ARR、NRR、Rule of 40、CAC Payback。
- 金融：ROE、ROA、净息差、成本收入比、P/B。
- 零售/平台：同店、GMV、Take Rate、库存周转。
- 工业：订单、产能利用率、CapEx/收入、ROIC、库存周转。
- 医疗/生物科技：研发投入、管线、专利和监管里程碑。

不要同时加入所有可得指标；超过 15 个指标时先删掉不能改变判断的列。

## 工作簿结构

默认使用一个清晰的分析表，依次包含：

1. 标题、同行列表、估值日期、币种和单位。
2. 经营数据与指标。
3. 估值数据与倍数。
4. 最大值、75 分位、中位数、25 分位和最小值。
5. 数据来源、口径和调整说明。

目标公司与同行顺序保持一致；估值倍数引用经营数据区，不重复硬编码收入、EBITDA 或净利润。

## 公式

派生值和统计值全部写 Excel 公式：

```excel
Gross Margin = Gross Profit / Revenue
EBITDA Margin = EBITDA / Revenue
EV/Revenue = Enterprise Value / LTM Revenue
EV/EBITDA = Enterprise Value / LTM EBITDA
P/E = Market Cap / Net Income
FCF Yield = LTM FCF / Market Cap
```

统计区间：

```excel
=MAX(range)
=QUARTILE(range,3)
=MEDIAN(range)
=QUARTILE(range,1)
=MIN(range)
```

- 分母为零或指标无意义时显示 `N/A`，不要用 0 掩盖。
- EV 倍数使用企业价值；P/E 使用股权价值，不能混用。
- 分子和分母必须对应相同期间，LTM、NTM、FY 不混在同一列。
- 绝对规模列可不做统计；增长、利润率和倍数必须做统计。

## 电子表格规则

- 实时 Excel 使用原生 Excel 能力；独立 `.xlsx` 使用电子表格技能/openpyxl。
- 历史和市场输入可硬编码，所有派生值、倍数和统计必须为公式。
- 蓝色字体=输入，黑色=公式，绿色=跨表引用；用户模板覆盖默认样式。
- 输入单元格在写入时立即添加来源批注。
- 金额、百分比、倍数、年份和负数使用一致格式并标明单位。
- 结构和输入完成后分别检查，再构建公式和统计；不要整表写完才第一次验证。

## 工作流

1. 定义问题、估值日期、同行和指标。
2. 建表头与单位，锁定布局。
3. 拉取原始数据，统一币种、期间和会计口径；记录来源和调整。
4. 与用户核对同行和输入期次。
5. 写经营指标公式并检查利润率、增长率和异常值。
6. 写估值倍数，确认分子分母及 LTM/NTM 口径。
7. 加统计区间，说明目标公司相对位置及溢价/折价依据。
8. 重算、检查公式错误并打开/渲染工作簿。

## 交付前检查

- [ ] 同行与目标公司在业务、地域和阶段上可比，排除理由有记录。
- [ ] 估值日期、币种、单位、财年和 LTM/NTM 定义清楚。
- [ ] 每个硬编码输入有来源批注；关键数据已交叉验证。
- [ ] 派生指标和统计区间为公式，不重复硬编码。
- [ ] EV/Revenue、EV/EBITDA、P/E 的分子分母口径正确。
- [ ] 最大值、75 分位、中位数、25 分位、最小值完整。
- [ ] 没有 `#REF!`、`#DIV/0!`、`#VALUE!` 或隐藏的零值替代。
- [ ] 目标公司相对同行的结论由表中数字支持。
- [ ] 工作簿可打开、列宽可读、格式一致。

只交付最终 Excel 和用户明确要求的简短结论，不生成额外模板或复盘文档。
