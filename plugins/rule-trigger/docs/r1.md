# R1 动态主线强度

R1 回答两个问题：**市场当下最强的是哪些行业？这些行业里，资金真正选中了哪些股票？**

旧版把“AI 白名单”固定当主线，覆盖约三分之一市场，而且历史回测存在白名单前视。当前版改成市场驱动：先用申万一级行业指数的 5 日、20 日涨幅找动态主线，再按个股 20 日涨幅做行业内排名。AI 不再享有固定加分；电子、计算机、通信等行业只有真实走强时才进入主线。

R1 是状态排序，不是买点。动手时机仍看 R0/R9。

## 数据与缓存

- 行业行情：申万 31 个一级行业官方指数日线。
- 行业归属：申万个股行业分类变动历史，按 `start_date <= 评分日` 取最后一条。
- 个股行情：`$R0_DATA_DIR`（缺省 `~/.r0-data`）后复权日 K。
- 本地缓存：`sw1_sector_close.parquet`、`sw_industry_history.csv`，首次使用自动下载，超过 7 天自动刷新。

强制刷新：

```bash
python3 r1.py --refresh-industries
```

行业分类采用当前下载文件里的历史记录，虽然按生效日还原，仍可能包含后来修订；严格无修订偏差需要从现在开始保存每日快照。

## 动态主线行业

对每个评分日 `t`：

```text
ret5_s  = 行业指数 close(t) / close(t-5)  - 1
ret20_s = 行业指数 close(t) / close(t-20) - 1

p5_s   = ret5_s  在有效一级行业中的百分位
p20_s  = ret20_s 在有效一级行业中的百分位
heat_s = 0.4 × p5_s + 0.6 × p20_s
rank_s = heat_s 在有效一级行业中的百分位
```

行业同时满足以下条件才算动态主线：

```text
rank_s >= 0.85       # 综合强度前15%
p20_s >= 0.60        # 20日不能掉出前40%
p5_s >= 0.50         # 5日不能掉到后半区
ret20_s > 0          # 20日必须实际上涨
有效成员 >= 20只
```

这通常选出 4～6 个一级行业；弱市允许没有主线。

## 行业内个股分档

只在动态主线行业里，计算个股 20 日涨幅在本行业的平均名次百分位 `stock_rank`：

| R1 | 条件 | 含义 |
|---|---|---|
| 5 | `stock_rank >= 0.93` | 动态主线行业内前 7%，龙头层 |
| 4 | `0.66 <= stock_rank < 0.93` | 行业内偏强 |
| 3 | `0.33 <= stock_rank < 0.66` | 行业内中游 |
| 2 | `stock_rank < 0.33` | 行业是主线，但个股掉队 |
| 1 | 所属行业不是动态主线 | 主线门槛没过 |
| N/A | 行业归属、行业指数或同日行情不足 | 不打分 |

北交所和科创板 688 沿用原回测口径，不打分。并列股票使用平均名次，不按代码硬拆。

## 怎么查

```bash
python3 r1.py 胜宏科技 603228 sz300476
python3 r1.py --today            # 动态主线行业 + R1=5 股票
python3 r1.py --today --min 4
python3 r1.py                    # 纯函数自检
```

输出会同时给出行业名称、行业 5/20 日涨幅、行业综合 rank、个股 20 日涨幅和行业内 rank。

## 2026-07-12 同仓回测

口径：数据截至 2026-07-03；剔除北交所/688；样本约 13 个月；每 5 个交易日一个锚点；标签为未来 10 个交易日最高收盘价相对锚点收盘触及 +10%/+20%。

| 规则 | R1=5 n | hit10 | hit20 |
|---|--:|--:|--:|
| 旧 AI 白名单 R1 | 4,688 | 42.8% | 22.1% |
| 新动态行业 R1 | 2,604 | 40.2% | 20.1% |

动态版单因子略低、覆盖更窄，但去掉了固定 AI 门，并新增了 1,347 条旧 AI R1=5 没覆盖的行业龙头样本；这部分 hit10=35.9%、hit20=18.1%，明显高于全市场基础。

同仓 R7+R1 组合回测（未来 20 日最高收盘触及口径）：

| 评级 | 旧版 n | 旧 hit10/hit20 | 动态版 n | 动态 hit10/hit20 |
|---|--:|---:|--:|---:|
| S | 888 | 54.2% / 34.8% | 435 | **57.0% / 39.1%** |
| A | 3,593 | 48.2% / 28.3% | 1,935 | **48.5% / 29.3%** |

新规则更严格，S/A 样本约减半，但组合质量没有下降；S 档四个季度 hit10 分别为 50.0% / 56.7% / 50.0% / 71.4%。

## 诚实边界

- 回测只覆盖约 13 个月，分季度稳定不等于跨牛熊验证完成。
- 当前本地票池含幸存者偏差；退市和长停票覆盖不完整。
- 申万历史分类文件可能被事后修订；从规则上线日起保存每日快照，才能彻底消除版本偏差。
- `hit10/hit20` 是窗口内最高收盘“触及”，没有退出规则，不是可实现胜率。
- R1 本质仍是动量状态排序，不能代替基本面候选池或 R0/R9 时机确认。
