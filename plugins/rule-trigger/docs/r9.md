# R9 下跌反转

R9 回答一个窄问题：**这只票是不是「刚走完一段明确下跌 → 横住企稳 → 最近 5 个交易日出现放量大阳收复失地」的反转确认形态？**

它是扳机型信号（同族 R0，多一个前置背景要求）。回测实证只有 5 分是钱桶；就算 5 分，六成事件 10 天内也冲不到 10%——给的是赔率不是确定性，必须先有基本面候选池。

## 文件

```text
plugins/rule-trigger/scripts/r9.py    # 单票/多票即时查、全市场 R9 名单（自检：无参运行）
```

回测/迭代闭环在私有扫描器仓（vault `03-Trading/code/r9_reversal.py`，step=1 逐日锚点全数据回放 + 对照组 + 季度稳定性），本插件只带即时查。

## 怎么查

```bash
cd plugins/rule-trigger/scripts

python3 r9.py 达瑞电子 603228 sz300476
python3 r9.py --today                # 默认只列 R9=5
python3 r9.py --today --min 4
python3 r9.py --today --include-bj688
python3 r9.py                        # 自检
```

- `--today` 默认排除 `bj*` 和 `sh688*`；单票查询不受这个过滤影响。
- 数据用 `$R0_DATA_DIR`，缺省 `~/.r0-data`，和 r0-trigger 共用。

## 打分公式

窗口（相对信号日 t）：下跌段 D=[t-27, t-8] 共 20 根；企稳段 S=[t-7, t-1] 共 7 根；判定窗=最近 5 个交易日逐根找，取最强一根。核心参数在 `r9.py`：

```python
DOWN_LEN, STAB_LEN, JUDGE_LEN = 20, 7, 5
DOWN_RET = -0.12          # 下跌段跌幅门槛
LOW_TOL = 0.99            # 企稳不破低容忍
STAB_VOL = 1.0            # 企稳段均量/下跌段均量 上限
WEAK_PCT, WEAK_VR = 0.03, 1.3
MID_PCT, MID_VR = 0.04, 1.5
STRONG_PCT = 0.07         # 5分强阳(量能路径已实证无效,不设)
BREAK_N4, BREAK_N5 = 10, 20
ONECHAR_TURNOVER = 0.02   # 一字板降档
```

| R9 | 条件 |
|---|---|
| 5 | 背景 + 涨≥7% 且量比5≥1.5 且收复20日高（收盘>前20日最高收盘） |
| 4 | 背景 + 涨≥4% 且量比5≥1.5 且破10日高 |
| 3 | 背景 + 涨≥3% 且量比5≥1.3 |
| 2 | 只有背景（下跌≤−12% + 企稳不破低且缩量），等确认 |
| 1 | 无下跌企稳背景 |

背景成立的一个隐含特性：底部K线要老化出企稳窗（>7 天）后背景才成立——**底刚砸出来不算企稳**，V 型底当天反包不给分，设计本意。

## 回测方法与结论（2026-07-07，扫描器仓 10 轮迭代）

协议：step=1 逐日锚点（无相位漏采），hfq，2025-05-28~2026-07-06，剔 bj*/sh688*，100.9 万样本；结果窗=之后 **10 日**最大收盘涨幅（比 R0/R7 的 15 日短，横比要换算）；事件同票 5 日去重；带对照组（同样放量突破但无下跌企稳背景）。

| 桶 | 事件 n | hit10 | hit20 |
|---|--:|--:|--:|
| 基础命中 | — | 18.0% | 5.9% |
| 对照组（无背景放量突破） | 22295 | 28.5% | 11.9% |
| R9=3 | 899 | 22.4% | 8.2% |
| R9=4 | 946 | 22.8% | 8.6% |
| **R9=5** | **175** | **38.3%** | **18.9%** |

- 季度稳定（5 分 hit10）：2025Q3 36.4 / 2025Q4 36.5 / 2026Q1 40.0 / 2026Q2 39.4。
- 10 轮迭代的两个关键认知：①**有效成分是 7% 大阳 + 收复 20 日高**，量比加码、贴底买、平台紧致度、收紧下跌企稳阈值全部无效或更差；②**前置背景的价值依赖确认强度**——弱确认下"下跌企稳"是减分项（输对照组），强确认下才是加分项（38.3 vs 28.5）。
- 5 分事件全市场月均约 15 个，稀疏扳机不是排序因子。

**诚实边界**：①只回放了一个约 13 个月的周期（分季度稳定 ≠ 跨行情稳健），弱于 R0/R7 的 14 窗结论，属「初版有 edge、待 forward 检验」；②step=1 结果窗重叠，显著性看方向和 lift、别信样本量；③hit 是窗内最大收盘涨幅，不是可实现收益（无退出规则）；④票池=今日在市票（轻微幸存者偏差）。

## 与 R0 / R7 的分工

- **R0**：放量强阳突破，不看前置背景，覆盖面广——通用扳机。
- **R7**：试盘后缩量回踩，观察形态不是买点。
- **R9**：R0 的"下跌企稳背景加强版"——只在刚跌完企稳的票上找更强的确认（7%、收复20日高），更稀疏但单桶命中更高。R9=5 与 R0≥4 的重叠度/独立增量待验证。
