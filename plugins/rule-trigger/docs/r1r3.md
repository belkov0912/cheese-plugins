# R1R3 主线内强度

R1R3 回答一个窄问题：**这只票过没过 AI 主线门槛（白名单），过了的话 20 日涨幅在板块内排第几个百分位？**

它是旧 R1（主线财报）与 R3（主线兑现度）合并后的升级版。旧实现因为缺 as-of 财报和行业收入占比数据，退化成"在不在白名单"的二值门（1928 只、约 35% 市场都是满分）；新版用**板块内相对强度 rank** 当"主线兑现度"的市场代理，把二值门拆成 5 档。状态排序不是扳机——动手时机看 R0/R9。

## 文件

```text
plugins/rule-trigger/scripts/r1r3.py         # 单票/多票即时查、板块内强度前排名单（自检：无参运行）
plugins/rule-trigger/scripts/ai_tickers.txt  # AI 白名单快照(扫描器 build_ai_tickers.py 生成的副本)
```

回测/迭代闭环在私有扫描器仓（vault `03-Trading/code/r1r3_mainline.py`，宽表日历对齐 + 对照组 + 季度稳定性），本插件只带即时查。

## 怎么查

```bash
cd plugins/rule-trigger/scripts

python3 r1r3.py 胜宏科技 603228 sz300476
python3 r1r3.py --today            # R1R3=5 前排名单,按 rank 降序
python3 r1r3.py --today --min 4
python3 r1r3.py                    # 自检
```

- rank 要在全板块内算，**单票查询也需要本地仓**（`$R0_DATA_DIR`，缺省 `~/.r0-data`），没有联网兜底。
- 北交所/科创板 688 不在回测口径内，一律不打分。

## 打分公式

rank = 个股 20 日涨幅在白名单板块内当日的百分位（板块成员=白名单 ∩ 本地仓有当日数据 ∩ 非 bj/688，约 1200 只）：

| R1R3 | 条件 | 含义 |
|---|---|---|
| 5 | rank ≥ 0.93 | 板块内前 7%，主线兑现正落在这只票上 |
| 4 | 0.66 ~ 0.93 | 板块内偏强 |
| 3 | 0.33 ~ 0.66 | 板块内中游 |
| 2 | < 0.33 | 主线掉队者（反面信号） |
| 1 | 不在白名单 | 主线门槛没过 |

核心参数在 `r1r3.py`：`RET_N = 20`、`STRONG_RANK = 0.93`、档界 `0.33/0.66/0.93`。

## 回测方法与结论（2026-07-07，扫描器仓 10 轮迭代）

协议：宽表按日历对齐，锚点每 5 个交易日共 48 个日期、20.8 万样本（hfq，2025-05-28~2026-07-06，剔 bj/688）；结果窗=之后 **10 日**最大收盘涨幅；基础命中 hit10=17.7%、hit20=5.8%；对照组=非白名单+全市场 rank 同门槛的强动量票。

| 桶 | n | hit10 | hit20 |
|---|--:|--:|--:|
| 1（非白名单） | 139781 | 15.2% | 4.5% |
| 2（主线掉队者） | 22515 | 17.4% | 5.0% |
| 3 | 22530 | 18.8% | 6.0% |
| 4 | 18403 | 29.5% | 11.7% |
| **5** | **4784** | **41.7%** | **21.0%** |
| 白名单整体（旧二值门的"5分"） | 68232 | 22.8% | 8.2% |
| 对照组（非 AI 同等动量） | 7877 | 34.4% | 15.0% |

- 分档完美单调；白名单内部逐日 IC +0.113、79% 天为正；季度稳定（5 分 hit10）：2025Q2 41.8 / Q3 42.6 / Q4 33.6 / 2026Q1 32.9 / Q2 58.2。
- 迭代关键认知：①板块热度做档位/做门/做超额三种变体全部无效，**板块内相对强度才是"兑现度"的有效代理**；"主线热但个股没跟上"反而是白名单里最差的状态（热主线的掉队者被资金否决过）。②**AI 帽子有独立增量但动量是大头**：同等动量强度下戴帽 41.7 vs 不戴 34.4（+6~8pp）；rank 推到 0.97 时增量缩水——极限动量不分主线。

**诚实边界**：①**白名单是当前名单，历史打分有前视**，所有数字只能当上界读；②单周期约 13 个月；③step=5 < fwd=10 结果窗半重叠、状态规则同票连续在档，显著性看方向和分段；④hit 是窗内最大收盘涨幅，非可实现收益；⑤本质是动量族信号，进综合分前要查与 R0 的重叠度。

## 与 R0 / R7 / R9 的分工

R1R3 排序"主线兑现正落在谁身上"（每天全板块都有分）；R0/R9 是扳机（哪天动手）；R7 是观察形态。组合用法：候选池 × R1R3 前排交叉 → 等 R0/R9 扣扳机。
