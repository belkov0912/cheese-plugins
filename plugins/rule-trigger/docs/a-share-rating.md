# A股最近观察评级（a-share-latest-rating）

把 R7（试盘后回踩形态）和 R1（动态行业主线强度）组合成 S/A/B/C/D/N/A 观察评级。**它是观察池评级器，不是交易建议**：R7 不是买点、R1 不是扳机，动手时机仍看 R0/R9。

## 怎么查

```bash
cd plugins/rule-trigger/scripts
python3 a_share_latest_rating.py latest --min-rating A --top 200
python3 a_share_latest_rating.py latest 胜宏科技 603228 sz300476
python3 a_share_latest_rating.py backtest --step 10 --random-n 10000
python3 a_share_latest_rating.py
```

- 单票查询也要全市场本地仓，因为 R1 需要同日行业内排名。
- R1 首次使用会下载申万行业指数和历史行业归属，缓存在 `$R0_DATA_DIR`。
- bj*/sh688* 一律不覆盖。
- 仓过旧或半更新（追平当日的票 <95%）默认拒绝；`--allow-stale` 只用于调试或已知节假日/收盘窗口。

## 组合分档规则（`v3_dynamic_sw1_r1`）

| 评级 | 规则 | 含义 |
|---|---|---|
| S | `R7>=4` 且 `R1=5` | 动态主线行业龙头 + 试盘回踩确认 |
| A | 非 S，`R1>=4` 且 `R7+R1>=8` | 强观察 |
| B | 非 S/A，`R7>=4` 或 `R1>=4` | 一个核心因子强 |
| C | 其他 | 证据不足 |
| D | `R1<=2` 且 `R7<=2` | 弱或反面 |
| N/A | 数据、行业归属或名称解析不足；仓过旧半更新；bj/688 | 不评级 |

评级边界没有随 R1 重定义一起改。本轮只替换固定 AI 门为动态行业门，方便做同仓归因。

## 口径与风险

- R1 行业行情用申万一级行业指数；行业归属按历史 `start_date` 还原；个股按行业内 20 日涨幅排名。
- 申万历史分类文件是当前下载版本，可能包含后来对历史记录的修订；严格无修订偏差需保存每日快照。
- 当前本地票池有幸存者偏差；step=10 小于20日标签窗，样本重叠。
- `hit10/hit20` 是未来窗口内最高收盘“触及”，没有退出规则，不是可实现胜率。
- downside 是未来20日盘中最低相对锚点收盘，不是峰谷最大回撤。

## 与其他 skill 的分工

R1 找“当前主线行业和行业前排”，R7 看“试过盘并回踩没有”，两者组合成观察评级；R0/R9 才回答“哪天确认”。
