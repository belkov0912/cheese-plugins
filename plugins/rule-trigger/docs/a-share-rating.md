# A股最近观察评级（a-share-latest-rating）

把 R7（试盘后回踩形态）和 R1（AI 主线内相对强度）两个因子组合成 S/A/B/C/D/N/A 观察评级。规则来自本地历史行情仓回测，脚本的"最近日查询"与"历史回测"共用同一个 `rate_combo()`。**是观察池评级器，不是交易建议**：R7 不是买点、R1 不是扳机，动手时机仍看 R0/R9。

## 文件

```text
plugins/rule-trigger/scripts/a_share_latest_rating.py   # latest 最近日评级 + backtest 历史回测（自检：无参运行）
plugins/rule-trigger/out/a-share-latest-rating/          # 回测报告与明细 CSV
```

依赖同插件的 `r7.py`（R7 打分）、`r1.py`（R1 rank / 白名单）、`store.py`（本地仓）。

## 怎么查

```bash
cd plugins/rule-trigger/scripts

python3 a_share_latest_rating.py latest --min-rating A --top 200   # 全市场观察池
python3 a_share_latest_rating.py latest 胜宏科技 603228 sz300476    # 单票/多票（多带 r7_desc 列）
python3 a_share_latest_rating.py backtest --step 10 --random-n 10000 # 历史回测
python3 a_share_latest_rating.py                                    # 自检
```

- 单票查询也要本地仓（R1 rank 要在全板块内算，没有联网兜底）。
- bj*/sh688* 一律不覆盖（涨跌幅制度不同、不在回测口径）。
- 仓过旧或半更新（追平当日的票 <95%）→ 拒绝并提示 r0-data；`--allow-stale` 用于调试或已知节假日/收盘窗口。

## 组合分档规则（`v2_a_requires_r1_4`）

| 评级 | 规则 | 含义 |
|---|---|---|
| S | `R7>=4` 且 `R1=5` 且 `R7+R1>=9` | 主线前排 + 试盘回踩确认 |
| A | 非 S，`R1>=4` 且 `R7+R1>=8` 且至少一核心因子>=4 | 强观察，组合稳定优于单因子 |
| B | 非 S/A，`R7>=4` 或 `R1>=4` | 一个核心因子强 |
| C | 其他 | 证据不足 |
| D | `R1<=2` 且 `R7<=2` | 弱或反面 |
| N/A | 数据不足/名称歧义/仓过旧半更新/bj·688 | 不评级 |

## 回测口径与结论

- 标签：`hit10/hit20` = 未来 20 个交易日内**最高收盘价**相对锚点收盘 ≥10%/≥20%（收盘口径，与 r7/r9/r1 定版一致、可横比）。
- downside：「20日最低(相对入场)」= 未来 20 日盘中最低价相对锚点收盘的跌幅，非峰谷式最大回撤。
- 锚点每 10 个交易日一个（step=10 < 标签窗 20，样本重叠、状态跨锚点持续，有效独立样本远小于名义 n）。
- 前视/偏差（数字都是上界）：AI 白名单前视 + 当前在市票池的幸存者偏差 + hit 是触及型标签。
- **数字随回测当日的仓快照而变，不承诺复现某份历史数字。**

参考形状（收盘口径，2026-07-08 快照，样本区间 2025-08-06~2026-06-08，91122 条）：

| 口径 | n | hit10 | hit20 |
|---|--:|--:|--:|
| 全市场随机 | 10000 | 31.3% | 13.2% |
| R7 单因子 | 15716 | 38.6% | 18.9% |
| R1 单因子 | 10179 | 47.8% | 26.7% |
| R1=5 前排 | 2093 | 57.9% | 36.4% |
| S 档 | 995 | 57.5% | 34.2% |
| A 档 | 3697 | 49.7% | 29.1% |

季度稳定（S 档 hit10）：2025Q3 52.6% / Q4 47.9% / 2026Q1 56.3% / Q2 73.9%。分档单调、组合优于单因子（S 档约随机 1.8 倍），但都是上界，不是可实现胜率。

## 与其他 skill 的分工

R1 排序"主线兑现落在谁身上"、R7 看"试过盘没有"，两者组合成观察评级；R0/R9 才是"哪天动手"的扳机。用法：候选池 × 高评级交叉 → 等 R0/R9 扣扳机。

## 维护备忘

改档位常量（S/A/B/C/D 边界）先跑 `python3 a_share_latest_rating.py` 自检；R1 白名单快照随 `ai_tickers.txt` 同步（见 r1 文档）。
