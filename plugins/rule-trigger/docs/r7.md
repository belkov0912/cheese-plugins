# R7 试盘后回踩

R7 回答一个窄问题：**最近 20 个交易日里，有没有出现「相对自身明显放量试盘 -> 最近 5 日缩量回踩」的形态？**

它是观察信号，不是买点。R7 高只说明资金试过盘、最近可能在缩量消化抛压；真正动手仍要等 R0 放量强阳突破，或用户自己的再次转强信号。

## 文件

```text
plugins/rule-trigger/scripts/r7.py           # 单票/多票即时查、全市场 R7 高分名单
plugins/rule-trigger/scripts/backtest_r7.py  # 新版 R7 回测，对比旧版 R7
plugins/rule-trigger/out/回测_R7_<date>.md   # 回测汇总报告
plugins/rule-trigger/out/回测_R7_明细_<date>.csv
```

## 怎么查

```bash
cd plugins/rule-trigger/scripts

python3 r7.py --today --min 5
python3 r7.py --today --include-bj688

```

- 如果当前 `python3` 缺 `pyarrow`，用 `/usr/bin/python3`，或先给当前 Python 安装依赖。

## 试盘是什么意思

试盘就是资金先用一根明显异动的 K 线探路：看看上方抛压大不大、有没有跟风盘、卖盘会不会砸下来。它不是买点本身，而是资金留下的脚印。

新版 R7 不再死用「20日均换手 8%-15%」这种绝对阈值。很多大票、机构持仓票平时换手很小，哪怕明显放量也不到 8%。所以 R7 改看相对自身的异动。

## 打分公式

核心参数在 `r7.py`：

```python
SETUP_LEN = 20
PULLBACK_LEN = 5
REL_LOOKBACK = 60

PROBE_PCT = 0.07
PROBE_VOLRATIO5 = 1.8
PROBE_REL_TURNOVER = 2.0
PROBE_REL_AMOUNT = 2.0
PROBE_LIMIT_PCT = 0.095
PULLBACK_RATIO_STRONG = 0.8
PULLBACK_RATIO_LOOSE = 1.0
STRUCTURE_BREAK_BUFFER = 0.03
LIGHT_ACTIVE_RATIO = 1.3
```

基础指标：

```text
pct[i] = close[i] / close[i-1] - 1
volratio5[i] = volume[i] / mean(volume[i-5 : i])
turnover_ratio60[i] = turnover[i] / median(turnover[i-60 : i])
amount_ratio60[i] = close[i] * volume[i] / median(close[j] * volume[j], j=i-60..i-1)
break5[i] = close[i] > max(close[i-5 : i])
```

**试盘日成立**：

```text
单日涨幅 >= 7%
且满足以下任一：
1. 5日量比 >= 1.8
2. 当日换手 >= 近60日换手中位数的 2倍
3. 当日成交额 >= 近60日成交额中位数的 2倍
4. 当日近似涨停/20cm强阳，且突破前5日高点
```

其中 **5日量比** = `试盘日成交量 / 试盘日前5个交易日平均成交量`，不包含试盘日自己。

**回踩成立**：

```text
active_avg = mean(volume[probe_idx-2 : probe_idx+3])
last5_avg = mean(volume[-5:])
pullback_ratio = last5_avg / active_avg

platform_low = min(close[probe_idx-5 : probe_idx])
pullback_low = min(close[-5:])
structure_ok = pullback_low >= platform_low * 0.97
```

也就是：最近 5 日量能要相对试盘活跃段收缩；结构上允许最多跌破试盘前平台低点约 3%。

## 分数含义

| 分数 | 代码定义 | 白话 |
|---|---|---|
| R7=5 | 有试盘；`pullback_ratio <= 0.8`；`structure_ok = true` | 试盘后明显缩量回踩，结构没破 |
| R7=4 | 有试盘；`pullback_ratio <= 1.0`，但没达到 5 分条件 | 有回踩/量能收缩，但不够完美 |
| R7=3 | 有试盘但回踩不缩量，或最近 5 日刚试盘还没完成回踩 | 刚动过，热度更近，但没证明抛压消化 |
| R7=2 | 无试盘，但 `max(量比5, 相对换手, 相对成交额) >= 1.3` | 只有轻微活跃 |
| R7=1 | 以上都没有 | 没看到 R7 信号 |

注意：回测里 `R7=3` 短期表现反而最强，所以不要机械理解成 `5 > 4 > 3`。更合理的读法是：

```text
R7=3：刚试盘/还热
R7=4/5：试过盘并回踩，适合进观察池等 R0
R7=1/2：R7 形态不明显
```

## 为什么试盘后还要回踩

「试盘 + 突破前高」只说明资金冲过一次，还不能说明抛压被消化。

好的回踩应该是跌不深、量缩下来，说明卖盘释放后下面有人接。R7 的完整逻辑是：

```text
试盘突破 -> 回踩缩量不破 -> 再转强，才更像启动前结构
```

没有回踩、直接主升的票交给 R0 扳机；冲高后放量砸回平台的票，容易是假突破，不算好的 R7。

## 回测方法

```bash
cd plugins/rule-trigger/scripts
/usr/bin/python3 backtest_r7.py
```

`backtest_r7.py` 专门验证新版 R7 有没有 edge，不参与日常查分。方法：

1. 读取本地全A日K数据仓 `$R0_DATA_DIR`。
2. 默认排除 `bj*` 和 `sh688*`；需要包含时加 `--include-bj688`。
3. 每只股票按历史时间往回取锚点。
4. 默认每隔 15 个交易日取一个锚点；可用 `--step N` 改。
5. 在每个锚点，先把 K 线截断到锚点当天，再计算 `R7_new`，避免未来 K 线进特征。
6. 看锚点后 15 个交易日内最大收盘涨幅，作为结果标签。
7. 分别测试 θ=20%、30%、50% 三档成功率。
8. 比较不同 R7 分数的命中率、lift、Spearman IC、`R7>=4` 的精度/召回/覆盖率。
9. 同时对比 `R7_new`（新版相对放量试盘后回踩）和 `R7_old`（原 `score.py` 绝对换手口径）。

输出：

```text
plugins/rule-trigger/out/回测_R7_<date>.md        # 汇总报告：IC、分桶命中率、lift、召回
plugins/rule-trigger/out/回测_R7_明细_<date>.csv  # 每只股票、每个锚点的明细
```

**和 `docs/r0.md` 回测数字的可比性**：`backtest_r0.py` 与本回测共用 `bt_common.py` 的协议（同一锚点网格、结果标签、θ 网格、逐窗口 IC），默认票池也一致（都排除 `bj*/sh688*`）；唯一残留差异是窗口数——R7 要回看 60 日相对量能，最早两个窗口取不到（12 窗 vs R0 的 14 窗），横比时以重叠的 12 个窗口为准更严谨。

## 2026-07-05 回测结论

口径：默认排除 `bj* / sh688*`，12 个不重叠窗口，52133 条 stock-window，数据截至 2026-07-03。

核心结果：

| 指标 | R7_new | R7_old |
|---|---:|---:|
| 均值 IC | +0.11 | +0.10 |
| IC>0 窗口 | 11/12 | 11/12 |
| θ=20%，R7>=4 精度 | 15.6% | 14.6% |
| θ=20%，R7>=4 赢家召回 | 25.8% | 9.6% |
| θ=50%，R7>=4 精度 | 2.3% | 2.4% |
| θ=50%，R7>=4 赢家召回 | 28.5% | 11.6% |

结论：

- 新版 R7 有正 edge，且召回明显高于旧版。
- 分桶不单调，`R7=3` 在 θ=20%、30%、50% 三档都强于 `R7=4/5`。
- 因此新版 R7 适合先当观察名单信号，不适合直接把 `R7=5` 当最强买点。
- 下一轮如果要转正，重点不是证明有没有 edge，而是重新校准 3/4/5 的状态分层。
