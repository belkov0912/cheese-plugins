# R9 · 下跌反转即时查

回答一个很窄的问题：**这只票是不是「刚跌完一段（前置20日跌 ≥12%）→ 企稳一周（不破低、缩量）→ 最近 5 个交易日出现放量大阳收复失地」的反转确认形态？** 输出 1-5 分。

R9 是扳机型信号（同族 R0，比 R0 多一个前置背景要求）。回测实证：**只有 5 分是钱桶**——hit10=38.3%（基础 18% 的 2.1 倍）、hit20=18.9%（基础 5.9% 的 3.2 倍），且跑赢无下跌背景的纯放量突破对照组；3/4 分与基础差距小。

## 脚本与数据在哪

- **脚本**：本插件根目录的 `scripts/r9.py`（从本 SKILL.md 位置上两级即插件根；也可用 `${CLAUDE_PLUGIN_ROOT}/scripts`）。
- **数据**：用户本地，`$R0_DATA_DIR`（缺省 `~/.r0-data`），和 r0-trigger 共用。首次使用先走 **r0-data skill** 建仓；没建仓时单票查询会自动联网现抓，但 `--today` 全市场名单必须有本地仓。
- 依赖：同 r0-trigger，`python3` + `akshare`、`pandas`、`pyarrow`、`yaml`。缺包时先走 r0-data skill 的依赖自检和安装流程。

## 铁律

- **5 分才值得行动，3/4 分别当买点。** 回测里 3/4 分命中率只比随机高 4-5 个点，5 分才有 2-3 倍的赔率改善。
- **就算 5 分，六成事件 10 天内也冲不到 10%。** 给的是赔率不是确定性，必须配用户自己的基本面候选池。
- **不当选股器。** 和 R0 一样：先有池子，R9 只回答「这只反转确认了没有」。
- 只读、不写笔记；不下单、不荐股、不碰钱。
- 数字口径：后复权(hfq)日K，盘中也只按上一根完整收盘K线算。
- 诚实边界：回测只覆盖 2025-08~2026-06 一个约 13 个月的周期（分季度稳定），跨行情稳健性弱于 R0/R7 的 14 窗结论，属「初版有 edge、待 forward 检验」。

## 怎么跑

```bash
cd <插件根>/scripts
python3 r9.py 达瑞电子 603228 sz300476      # 逐票报 R9（名称或代码混着给都行）
python3 r9.py --today                        # 扫本地仓：R9=5 反转确认名单，默认排除 bj* / sh688*
python3 r9.py --today --min 4                # 放宽到 R9≥4（注意4分回测表现平平）
python3 r9.py --today --include-bj688        # 包含北交所和科创板 688
python3 r9.py                                # 无参 = 自检
```

- 名称解析靠本地 `universe.csv`（r0-data 建仓时保存）；解析不出唯一代码时，让用户给 6 位代码，别猜。
- `--today` 默认排除 `bj*` 和 `sh688*`（涨跌幅制度不同）；默认门槛 `--min 5`。
- 数据 <45 根返回「数据不足」，如实转告。

## R9 怎么打分

窗口（相对信号日 t）：**下跌段** = [t-27, t-8] 共 20 根；**企稳段** = [t-7, t-1] 共 7 根；判定窗 = 最近 5 个交易日逐根找信号，取最强一根。

**背景成立（A+B）**：下跌段收盘跌幅 ≤ −12%；企稳段最低收盘 ≥ 下跌段低点×0.99（不破低）且企稳段均量 ≤ 下跌段均量（缩量）。注意底部K线要老化出企稳窗（>7 天）后背景才成立——**底刚砸出来不算企稳**，V 型底当天反包不给分，这是设计本意。

| R9 | 条件 | 含义 |
|---|---|---|
| 5 | 背景 + 当日涨≥7% 且量比5≥1.5 且**收复20日高** | 反转确认：一根强阳吃掉整段下跌的套牢区（**唯一的钱桶**） |
| 4 | 背景 + 涨≥4% 且量比5≥1.5 且破10日高 | 冒出企稳平台，但没收复下跌失地 |
| 3 | 背景 + 涨≥3% 且量比5≥1.3 | 温和放量，观察 |
| 2 | 只有背景（下跌+企稳），还没放量上涨 | 观察池：等放量大阳收复20日高 |
| 1 | 无下跌企稳背景 | 无形态 |

一字板降档：信号日换手 <2% 且分数 ≥3 → 降一档（买不到的信号不可执行，同 R0）。

**收复20日高** = 信号日收盘 > 之前 20 个交易日的最高收盘（收盘比收盘）。这个窗深入下跌段内部，收上去等于把近一个月被套的人全部解放——和 4 分的"冒出平台"含金量差别很大（回测 hit10 38.3% vs 22.8%）。

**关键价三个数的含义**（单票模式会换算成屏幕价，回报时讲清）：
- **收复线** = 之前 20 日最高收盘——收上它才够 5 分确认；
- **下跌低点** = 下跌段最低收盘——企稳不能有效跌破的底线；
- **最近收** = 数据里最后一根收盘，方便和前两条比。

## 怎么回报

结论先行，别铺陈：

```text
XX R9=5，下跌反转确认。
证据：7月4日涨8.2%，量比5=2.3，收复20日高；背景是前置20日跌16%、企稳一周缩量到0.71倍。
但注意：5分给的是赔率不是确定性（回测里六成事件10天内也没冲到10%），要配你自己的候选池。
```

R9=2 的票要点破「还没确认」：报收复线在哪，等放量大阳收上去才算扣扳机。多只：逐行报，最后可汇总一行如 `达瑞 R9=1 · 胜宏 R9=2 · 某某 R9=5`。

## --today 名单怎么用

`--today` 默认只列 R9=5（反转确认扣了扳机的票），是「今天值得对照候选池看一眼」的名单，不是买入名单。全市场一天通常只有个位数到十几只，稀疏是正常的（回测里月均约 15 只）。

## 边界

- R0 放量强阳突破（不看前置背景）→ 用 r0-trigger。R9=5 本质是「带下跌企稳背景要求的更强 R0」，两者是同族扳机的不同挡位。
- R7 试盘后回踩 → 用 r7-trigger。
- 下载、更新、检查本地行情仓 → 用 r0-data。
- 基本面建池、估值、消息面、下单建议 → 不是本 skill。
- 本 skill 只做 R9 这一条下跌反转形态，不输出综合分。
