# R0 · 启动扳机即时查

回答一个很窄的问题：**这只票最近 5 个交易日里，出现过「放量强阳突破」那根启动确认K线没有？出现过的话成色多高？** 输出 1-5 分。

打分逻辑与翻倍股扫描器同源（`score_R0`，38 只翻倍股研究定阈值，14 个历史窗口验证：IC 均值 +0.07、5分组命中率约为全市场基础的 2 倍）。**不要重写打分**，只调本插件自带的脚本。

## 脚本与数据在哪

- **脚本**：本插件根目录的 `scripts/`（从本 SKILL.md 位置上两级即插件根；也可用 `${CLAUDE_PLUGIN_ROOT}/scripts`）。核心：`r0.py`（查询入口）、`store.py`/`fetch.py`（数据层）、`score.py`/`features.py`（打分）、`rules_config.yaml`（阈值快照）。
- **数据**：用户本地，`$R0_DATA_DIR`（缺省 `~/.r0-data`），**不在插件里**。首次使用先走 **r0-data skill** 建仓（全量约 45-90 分钟）；没建仓时单票查询会自动联网现抓（几秒/只，同样只取到上一收盘、带 15:05 北京时间保护），但 `--today` 全市场名单必须有本地仓。
- 依赖：`python3` + `akshare`、`pandas`、`pyarrow`、`yaml`。首次使用或报 ImportError 时，先跑 `python3 -c "import akshare, pandas, pyarrow, yaml"` 自检，缺包就征得用户同意后 `pip install -r <插件根>/scripts/requirements.txt`（r0-data skill 的第 0 步同款流程）。

## 铁律（先看这条）

- **R0 是扳机，不是选股器。** 它只回答「候选池里已看好的票，今天该不该扣扳机」。**没有基本面候选池就单看 R0 = 追涨**。每次输出末尾必须带一句提醒：R0 高 ≠ 会涨（满分票八成也不涨，IC 仅 +0.07），且等这根线出现再买、相对启动基准往往已让出头部 10~20%。
- **只读、不写笔记。** R0 每天在变，不往用户笔记里写。用户明确说「存档/记下来」才写。
- 不下单、不荐股、不碰钱。
- 数字口径：**后复权(hfq)** K线，数据新鲜到本地仓最后一根（`--today` 输出里带「数据截至」日期；过旧就提醒用户跑 r0-data 增量更新）。盘中问也是按上一根收盘K线算——本来就该看收盘扣扳机。

## 怎么跑

```bash
cd <插件根>/scripts
python3 r0.py 景旺电子 603228 sz300476     # 逐票报 R0（名称或代码混着给都行）
python3 r0.py --today                        # 扫本地仓：最近5个交易日内扣过扳机（R0≥4）的名单，默认排除 bj* / sh688*
python3 r0.py --today --min 5                # 只看 R0=5
python3 r0.py --today --include-bj688        # 包含北交所和科创板 688
python3 r0.py                                # 无参 = 自检
```

注意 `--today` 的语义是「**最近 5 个交易日的判定窗里**出现过扳机K线」，不是"仅今天涨的票"——扳机在本周早些时候扣的票也在名单里（证据里有具体日期）。停牌/数据过旧的票会自动剔除并在标题里注明。

- 名称解析靠本地 `universe.csv`（r0-data 建仓时保存）；**解析不出唯一代码时 CLI 会提示，转而让用户给 6 位代码**，别猜。
- `--today` 默认排除 `bj*` 和 `sh688*`；用户明确要北交所/科创板 688 时加 `--include-bj688`。单票查询不受这个默认过滤影响。
- 数据<50根（次新/停牌）返回「数据不足」，如实转告。

## 怎么读结果 / 怎么回报

CLI 每行形如：`R0=4  sh603228 景旺电子  R0=4 2026-06-30 涨8.3% 量比1.7 破5/10日高 换手9%`

**分数含义**（越高越强，全在这句证据里，念给用户听）：

| R0 | 含义 |
|---|---|
| 5 | 满级确认：涨幅≥7% + 5日量比>1.4 + 收盘**同破 5/10/20 日高**（吃掉近一个月套牢盘） |
| 4 | 强确认：涨幅≥7% + 放量 + 破5日高（未兼破10/20，只脱离最近一周盘整） |
| 3 | 缺一条腿：强阳破高但没放量，或放量破高但涨幅只 5~7% |
| 2 | 有动静不够格：放量中阳(4~7%)没破高，或破高但涨幅<5% |
| 1 | 无信号（今天没扣扳机） |

- 换手<2%（近似一字板/买不到）会自动降一档。
- **回报要脱水、结论先行**：先说分和「扣没扣」，再念证据数字，最后补那句铁律提醒。
- 多只：逐行报，最后可汇总一行如 `景旺 R0=1 · 胜宏 R0=1 · 利安隆 R0=5`。

## --today 名单怎么用

强动量行情里 R0≥4 可能有几百只——**这正说明 R0 不能单用**。回报时点破：这是「全市场今天扣了扳机的票」，要拿它去**交叉用户自己的基本面候选池**（主线 + 好财报 + 合理市值那类事前过滤），落在交集里的才值得看。

## 边界（别越界）

- 建池 / 选哪只 / 消息面 / 估值 → 不是本 skill。
- 下载、更新、检查本地行情仓 → 走 **r0-data** skill。
- 本 skill 只做 R0 这一条扳机，不输出 R1-R8 或综合分。
