# R1 · 主线内强度即时查

回答一个很窄的问题：**这只票过没过 AI 主线门槛（白名单），过了的话它的 20 日涨幅在板块内排第几？** 输出 1-5 分。

这是旧 R1（主线财报）与 R3（主线兑现度）合并后的升级版：旧实现退化成"在不在白名单"的二值门（35% 市场都是满分），新版用**板块内相对强度 rank** 当"兑现度"的市场代理把它拆成 5 档。回测（2026-07-07 十轮迭代）：5 分档 hit10=41.7%（基础 2.4 倍）、hit20=21.0%（3.6 倍），五季全稳，比同等动量强度的非 AI 票稳定多 6-8 个百分点。

## 脚本与数据在哪

- **脚本**：本插件根目录的 `scripts/r1.py`；白名单快照 `scripts/ai_tickers.txt`（1928 只 6 位代码，扫描器 `build_ai_tickers.py` 生成的副本）。
- **数据**：用户本地，`$R0_DATA_DIR`（缺省 `~/.r0-data`），和 r0-trigger 共用。**注意：rank 要在全板块 ~1200 只内算，单票查询也必须有本地仓，没有联网兜底**——仓为空先走 r0-data skill 建仓。
- 依赖：同 r0-trigger（`python3` + `akshare`、`pandas`、`pyarrow`、`yaml`）。

## 铁律

- **状态排序不是扳机。** R1 高只回答"主线兑现正落在谁身上"，哪天动手看 r0-trigger（放量突破）或 r9-trigger（下跌反转确认）。
- **5 分才有含金量，2 分是反面信号**："在主线里但板块内 rank<0.33"的票命中率几乎等于非 AI 票——主线掉队者是被资金看过又否决的。
- **数字当上界读**：白名单是当前名单，回测给历史打分有前视（继承旧 R1/R3 的坑）；41.7% 不是实测胜率。
- 回测只覆盖约 13 个月单周期，属「初版有 edge、待 forward 检验」。
- 只读、不写笔记；不下单、不荐股、不碰钱。
- 数字口径：后复权(hfq)日K；北交所/科创板 688 不在回测口径内，一律不打分。

## 怎么跑

```bash
cd <插件根>/scripts
python3 r1.py 胜宏科技 603228 sz300476    # 逐票报 R1（名称或代码混着给）
python3 r1.py --today                      # 板块内强度前排(R1=5,约百只)
python3 r1.py --today --min 4              # 放宽到 ≥4
python3 r1.py                              # 无参 = 自检
```

- 名称解析靠本地 `universe.csv`（r0-data 建仓时保存）；解析不出唯一代码就让用户给 6 位代码。
- 停牌/数据不新鲜的票会明确报"当日板块排名缺数据"，提示跑 r0-data 增量。

## R1 怎么打分

rank = 个股 20 日涨幅在白名单板块（剔 bj/688 后约 1200 只有数据成员）内当日的百分位：

| R1 | 条件 | 含义 |
|---|---|---|
| 5 | rank ≥ 0.93 | 板块内前 7%——主线兑现正落在这只票上（**唯一有含金量的档**） |
| 4 | 0.66 ~ 0.93 | 板块内偏强 |
| 3 | 0.33 ~ 0.66 | 板块内中游 |
| 2 | < 0.33 | 主线掉队者——反面信号，约等于不在主线里 |
| 1 | 不在白名单 | 主线门槛没过 |

设计出处（回测实锤，详见 `docs/r1.md`）：板块热度做档位/做门的三种变体全部无效，**板块内相对强度才是"兑现度"的有效市场代理**；"主线热但个股没跟上"反而是白名单里最差的状态。

## 怎么回报

结论先行：

```text
胜宏 R1=2，主线掉队者。
在 AI 白名单里,但 20 日涨幅 -13.6%、板块内 rank 0.24——主线的钱没往它身上落,这个状态是反面信号。
慧博云通 R1=4,板块内偏强(rank 0.70),还没到前 7% 的兑现档。
提醒:这是状态排序,动手时机看 R0/R9 扳机;白名单有前视,分数当上界读。
```

多只：逐行报，最后汇总一行如 `胜宏 R1=2 · 慧博 R1=4 · 富满微 R1=5`。

## --today 名单怎么用

`--today` 列的是"主线兑现正落在谁身上"的排序（默认 R1=5，约百只，按 rank 降序），是**候选池的交叉参照**不是买入名单。正确用法：拿用户自己的基本面候选池对一下谁在前排，再看这些票的 R0/R9 扳机状态。

## 边界

- R0 放量突破扳机 → r0-trigger；R9 下跌反转确认 → r9-trigger；R7 试盘回踩观察 → r7-trigger。
- 下载、更新、检查本地行情仓 → r0-data。
- 白名单快照更新：扫描器仓跑 `build_ai_tickers.py` 后把 `ai_tickers.txt` 拷贝过来（README 同步备忘）。
- 基本面建池、估值、消息面、下单建议 → 不是本 skill。
