# A股最近观察评级

用这个 skill 查询 A 股最近一个完整交易日的观察评级。评级器不是拍脑袋规则：最终规则来自本地历史行情仓回测，脚本与最近日查询共用同一个 `rate_combo()`。

## 每次先做

先进入本插件根目录的 `scripts/` 并检查本地行情仓：

```bash
cd <rule-trigger插件根>/scripts
python3 store.py stat
```

如果全仓最新日早于 `store.py` 按北京时间算出的最近完整交易日，正式查询要返回 `N/A`，提示用户先跑 r0-data 增量更新。不要用过旧仓给用户正式评级；`--allow-stale` 只能用于调试或说明历史口径。

## 最近日查询

全市场观察池：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py latest --min-rating A --top 200
```

单票或多票：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py latest 胜宏科技 603228 sz300476
```

输出 `S/A/B/C/D/N/A`、代码、名称、R7、R1R3、rank、20日涨幅和分档原因。结论要说“观察评级”，不要写买入、卖出、仓位或目标价。

## 最终规则

版本：`v2_a_requires_r1r3_4`。

因子：

- `R7`：直接复用 rule-trigger 的 `r7.score_r7()`；只表示“试盘后回踩观察”，不是买点。
- `R1R3`：AI 白名单内 20 日涨幅横截面 rank 分档；只表示“主线兑现强度”，不是扳机。

分档：

| 评级 | 规则 | 含义 |
|---|---|---|
| S | `R7>=4` 且 `R1R3=5` | 主线前排且有试盘回踩形态确认，高 hit10 观察档 |
| A | 非 S，且 `R1R3>=4` 且 `R7+R1R3>=8` | 强观察，组合稳定优于单因子 |
| B | 非 S/A，且 `R7>=4` 或 `R1R3>=4` | 一个核心因子强，另一个未确认 |
| C | 非 S/A/B/D | 中性观察，证据不足 |
| D | `R1R3<=2` 且 `R7<=2` | 弱观察或反面信号 |
| N/A | 数据不足、名称无法解析、行情仓过旧、北交所或科创板 688 默认口径不覆盖 | 不评级 |

不要把 `R1R3=2` 全部强制打成 D。回测试过这个过滤，B 档几乎不提升，反而抬高 D 档命中率，已回退。

## 回测口径

复现命令：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py backtest --step 10 --random-n 10000
```

当前定版回测：

- 数据仓：`~/.r0-data`，全仓最新日 `2026-07-03`。
- 样本区间：`2025-08-08` 到 `2026-06-04`。
- 样本数量：`87000` 条 stock-anchor，默认排除 `bj*` 和 `sh688*`。
- 特征：每个历史日 t 只用 t 当天及以前 K 线；R7 先截断到 t 再算；R1R3 用 t 当天白名单横截面 20 日涨幅 rank。
- 标签：看 t 之后 5/10/20 个交易日最高价；`hit10` 是未来 20 日最高价相对 t 收盘涨幅至少 10%，`hit20` 是至少 20%。
- downside：记录未来 20 日最大回撤，以及 hit10 前路径回撤。
- 前视说明：AI 白名单是当前快照，历史 R1R3 是“上界版本”，不能当真实可交易胜率。

定版关键结果：

| 口径 | n | hit10 | hit20 | 平均20日最大涨幅 | 平均20日最大回撤 |
|---|--:|--:|--:|--:|--:|
| 全市场随机样本 | 10000 | 39.2% | 17.6% | 12.1% | -8.2% |
| R7 单因子 `R7>=4` | 14913 | 47.6% | 23.9% | 14.8% | -10.2% |
| R1R3 单因子 `R1R3>=4` | 9712 | 55.4% | 31.7% | 18.3% | -10.1% |
| 简单交集 `R7>=4 且 R1R3>=4` | 3439 | 57.1% | 33.6% | 19.5% | -10.8% |
| `R1R3=5` 单独前排 | 2009 | 63.9% | 40.8% | 22.9% | -12.7% |
| S 档 | 890 | 65.2% | 40.0% | 23.1% | -12.2% |
| A 档 | 3593 | 56.8% | 34.3% | 19.6% | -11.2% |

季度稳定性：S/A 在 `2025Q3`、`2025Q4`、`2026Q1`、`2026Q2` 均有样本；S 档单季样本数约 172 到 258，不是单季小样本。

## 回报边界

- 说“观察池”“观察评级”“候选”，不要说买入卖出。
- 明确 R7 不是买点，R1R3 不是扳机；真正动手仍要用户自己的交易系统或其他确认信号。
- 遇到行情仓过旧、数据不足、名称歧义、停牌导致缺排名、北交所或 688 默认不覆盖时，输出 `N/A` 并说明原因。
- 如果用户要求解释胜率，必须同时讲样本数、季度稳定性、hit10/hit20 和最大回撤，不只报一个命中率。
- 如果用户要求历史回测或修改规则，每轮只改一个最小规则单元，并保留/回退依据。
