# A股最近观察评级

用 R7（试盘后回踩）和 R1（动态主线行业内强度）给最近完整交易日做观察评级。最近日查询与历史回测共用同一个 `rate_combo()`。

## 每次先做

```bash
cd <rule-trigger插件根>/scripts
python3 store.py stat
```

如果全仓最新日早于北京时间最近完整交易日，或追平最新日的股票不足 95%，正式查询返回 `N/A`，提示先走 r0-data 更新。半更新会同时破坏 R1 的行业内排名。

`--allow-stale` 只用于调试，或法定节假日/刚过15:05而数据源尚未出当日K线时按全仓最新日查询；必须注明口径。

R1 的申万行业参考数据首次使用自动下载到 `$R0_DATA_DIR`，超过 7 天自动刷新；需要时可先跑：

```bash
python3 r1.py --refresh-industries
```

## 查询

```bash
python3 a_share_latest_rating.py latest --min-rating A --top 200
python3 a_share_latest_rating.py latest 胜宏科技 603228 sz300476
python3 a_share_latest_rating.py backtest --step 10 --random-n 10000
python3 a_share_latest_rating.py
```

输出 `rating/code/name/r7/r1`，以及 R1 的行业名、行业综合 rank、行业5/20日涨幅、个股行业内rank、个股20日涨幅和行业有效成员数。单票/多票模式额外输出 `r7_desc`。

## 最终规则

版本：`v3_dynamic_sw1_r1`。

- R7：直接调用 `r7.score_r7()`；是试盘回踩观察，不是买点。
- R1：申万一级行业先按5/20日涨幅选动态主线，再按个股20日涨幅做行业内分档；是状态排序，不是扳机。

| 评级 | 规则 | 含义 |
|---|---|---|
| S | `R7>=4` 且 `R1=5` | 动态主线行业龙头 + 试盘回踩确认 |
| A | 非S，`R1>=4` 且 `R7+R1>=8` | 强观察 |
| B | 非S/A，`R7>=4` 或 `R1>=4` | 一个核心因子强 |
| C | 非S/A/B/D | 证据不足 |
| D | `R1<=2` 且 `R7<=2` | 弱或反面 |
| N/A | 数据/行业归属不足、名称无法解析、仓过旧半更新、bj或688 | 不评级 |

不要把所有 `R1=2` 强制打成 D；仍需同时满足 `R7<=2`。

## 回测口径

- 默认排除 `bj*`、`sh688*`。
- 每个历史日只使用当日及以前的数据：R7先截断；R1行业指数、历史行业归属和个股收益都按锚点日计算。
- `hit10/hit20` = 未来20个交易日内最高收盘价相对锚点收盘触及 +10%/+20%。
- downside = 未来20日盘中最低相对锚点收盘，不是峰谷最大回撤。
- step=10 小于20日标签窗，样本重叠；当前在市票池含幸存者偏差。
- 申万历史分类按 `start_date` 还原，但当前下载文件可能含事后修订；严格无修订偏差需从现在起保存每日快照。
- hit 是触及型上界，没有退出规则，不是可实现胜率。

同仓对照（2026-07-12，数据截至2026-07-03）：

| 评级 | 旧AI版 n/hit10/hit20 | 动态行业版 n/hit10/hit20 |
|---|---:|---:|
| S | 888 / 54.2% / 34.8% | 435 / **57.0% / 39.1%** |
| A | 3593 / 48.2% / 28.3% | 1935 / **48.5% / 29.3%** |

动态版更严格、样本约减半；S档四季度 hit10 为50.0% / 56.7% / 50.0% / 71.4%。数字仅是样本形状，不保证未来，也不承诺复现其他仓快照。

## 回报边界

- 只说“观察池、观察评级、候选”，不说买入、卖出、仓位、目标价。
- 明确 R7 不是买点，R1 不是扳机；真正时机仍看 R0/R9 或用户自己的系统。
- 遇到仓过旧、半更新、行业参考数据缺日、行业归属不足、停牌、名称歧义、bj/688时，输出 `N/A` 并说清原因。
- 用户问“胜率”时，要点破 hit10/hit20 是触及型上界，同时给样本数、季度稳定性和 downside。
- 修改规则时每轮只改一个最小单元，并保留同仓旧版对照；本轮只替换 R1 主线门，没有改评级边界。
