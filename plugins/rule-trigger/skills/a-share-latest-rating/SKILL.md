# A股最近观察评级

用这个 skill 查询 A 股最近一个完整交易日的观察评级。评级器不是拍脑袋规则：最终规则来自本地历史行情仓回测，脚本与最近日查询共用同一个 `rate_combo()`。

## 每次先做

先进入本插件根目录的 `scripts/` 并检查本地行情仓：

```bash
cd <rule-trigger插件根>/scripts
python3 store.py stat
```

如果全仓最新日早于 `store.py` 按北京时间算出的最近完整交易日，或仓正处于半更新态（追平当日的票 <95%），正式查询会返回 `N/A` 并提示先跑 r0-data 增量更新——不要用过旧或半更新的仓给正式评级（半更新会让 R1 板块排名在残缺样本上算、评级失真）。`--allow-stale` 用于调试，或当天是法定节假日/刚过 15:05 收盘（当日数据 16:30 后才出）、确知仓其实不旧时按全仓最新日出结果。

## 最近日查询

全市场观察池：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py latest --min-rating A --top 200
```

单票或多票：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py latest 胜宏科技 603228 sz300476
```

输出 `S/A/B/C/D/N/A`、代码、名称、R7、R1、rank、20日涨幅和分档原因；单票/多票模式还会多带一列 `r7_desc`（R7 的证据化描述：试盘日、涨幅、量比、回踩缩量比等）。结论要说“观察评级”，不要写买入、卖出、仓位或目标价。

## 最终规则

版本：`v2_a_requires_r1_4`。

因子：

- `R7`：直接复用 rule-trigger 的 `r7.score_r7()`；只表示“试盘后回踩观察”，不是买点。
- `R1`：AI 白名单内 20 日涨幅横截面 rank 分档；只表示“主线兑现强度”，不是扳机。

分档：

| 评级 | 规则 | 含义 |
|---|---|---|
| S | `R7>=4` 且 `R1=5` | 主线前排且有试盘回踩形态确认，高 hit10 观察档 |
| A | 非 S，且 `R1>=4` 且 `R7+R1>=8` | 强观察，组合稳定优于单因子 |
| B | 非 S/A，且 `R7>=4` 或 `R1>=4` | 一个核心因子强，另一个未确认 |
| C | 非 S/A/B/D | 中性观察，证据不足 |
| D | `R1<=2` 且 `R7<=2` | 弱观察或反面信号 |
| N/A | 数据不足、名称无法解析、行情仓过旧/半更新、北交所或科创板 688（这几个 skill 一律不覆盖 bj/688） | 不评级 |

不要把 `R1=2` 全部强制打成 D。回测试过这个过滤，B 档几乎不提升，反而抬高 D 档命中率，已回退。

## 回测口径

跑一次回测（数字随当日仓快照而变，见下）：

```bash
cd <rule-trigger插件根>/scripts
python3 a_share_latest_rating.py backtest --step 10 --random-n 10000
```

口径要点：

- 数据仓：`~/.r0-data`，样本区间和样本数取决于**跑回测当日的仓有多长**（锚点从每只票最后一根 K 线倒推、按 step=10 生成，仓每加一天锚点整体平移）。默认排除 `bj*` 和 `sh688*`。
- 特征：每个历史日 t 只用 t 当天及以前 K 线；R7 先截断到 t 再算；R1 用 t 当天白名单横截面 20 日涨幅 rank。
- 标签：`hit10` = 未来 20 个交易日内**最高收盘价**相对 t 收盘涨幅 ≥10%，`hit20` ≥20%。**收盘口径，与 r7/r9/r1 定版一致、数字可横比**（旧版用盘中最高价、数字系统性偏高、不可比，已改）。
- downside：「20日最低(相对入场)」= 未来 20 日盘中最低价相对 t 收盘的跌幅，是相对入场价的最深处，**不是峰谷式最大回撤**。
- 样本重叠：step=10 < 标签窗 20 日，同票相邻样本标签窗重叠、且评级状态跨锚点持续，**有效独立样本远小于名义 n**，季度样本数别当独立样本读。
- 前视/偏差（数字都是上界，别当可交易胜率）：① AI 白名单是当前快照，历史 R1 前视；② universe 是当前在市票的本地仓，样本期内退市/长停票不在池，含幸存者偏差、命中率同向偏高；③ hit10 是"触及"型标签，真实退出规则拿不到最高收盘。

**这个 skill 会持续迭代，不承诺复现某一份历史数字**。下方结果是某次快照跑出来的形状参考（口径已是收盘价），要最新数字自己重跑上面的命令、以当次输出为准。

参考形状（收盘口径，2026-07-08 仓快照，样本区间 2025-08-06 ~ 2026-06-08，91122 条 stock-anchor，hit10/hit20 均为 20 日窗）：

| 口径 | n | hit10 | hit20 | 平均20日最大涨幅 | 平均20日最低(相对入场) |
|---|--:|--:|--:|--:|--:|
| 全市场随机样本 | 10000 | 31.3% | 13.2% | 9.4% | -8.2% |
| R7 单因子 `R7>=4` | 15716 | 38.6% | 18.9% | 11.7% | -10.1% |
| R1 单因子 `R1>=4` | 10179 | 47.8% | 26.7% | 15.3% | -9.9% |
| 简单交集 `R7>=4 且 R1>=4` | 3677 | 49.3% | 27.7% | 15.9% | -10.5% |
| `R1=5` 单独前排 | 2093 | 57.9% | 36.4% | 20.2% | -12.1% |
| **S 档** | 995 | **57.5%** | **34.2%** | 19.7% | -12.0% |
| **A 档** | 3697 | **49.7%** | **29.1%** | 16.2% | -10.6% |

季度稳定性（S 档 hit10）：2025Q3 52.6% / 2025Q4 47.9% / 2026Q1 56.3% / 2026Q2 73.9%，单季 n 约 175–323。

关键读法：分档单调（S≈R1=5 前排 > A > B > C，D 是反面），组合稳定优于单因子（S 档 hit10 57.5% 对随机 31.3%，约 1.8 倍）；但 hit10 是触及型上界、样本重叠、白名单前视，别把某个百分比当胜率。旧盘中口径下这些数字系统性偏高约 6–8pp（如 S 档曾报 65.2%），已改收盘口径、可与 r7/r9/r1 直接比。

## 回报边界

- 说“观察池”“观察评级”“候选”，不要说买入卖出。
- 明确 R7 不是买点，R1 不是扳机；真正动手仍要用户自己的交易系统或其他确认信号。
- 遇到行情仓过旧、数据不足、名称歧义、停牌导致缺排名、北交所或 688 不覆盖时，输出 `N/A` 并说明原因（脚本已按原因分别提示）。
- **hit10/hit20 不是胜率**：它们是"未来 20 日最高收盘价触及 +10%/+20%"的触及型统计，真实退出规则拿不到那个最高点，任何一个百分比都不是可实现胜率。用户问"能不能赚/胜率多少"时，要点破这是触及型上界，并同时讲样本数、季度稳定性、hit10/hit20 和 downside（20日最低相对入场），别只丢一个数字。
- 仓过旧/半更新：脚本按"追平当日的票 <95%"拦截并提示；若当天是法定节假日或刚过 15:05 收盘（当日数据 16:30 后才出），仓其实不旧，可用 `--allow-stale` 按全仓最新日出结果并注明口径。
- 如果用户要求历史回测或修改规则，每轮只改一个最小规则单元，并保留/回退依据。回测数字随仓快照变、不承诺复现某份历史数字。
