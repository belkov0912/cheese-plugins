# Task 4：图表生成

## 目标与前置条件

生成 25-35 张可直接嵌入首次覆盖报告的 PNG/JPG 图表，并打包为 `[Company]_Charts_[Date].zip`。

开始前必须确认：

- Task 1 研究文档存在，且包含公司历史、管理层、产品、客户、竞争格局和 TAM。
- Task 2 模型存在且可读，包含产品/地区收入、利润率、现金流和情景数据。
- Task 3 估值完成，包含 DCF、敏感性、可比公司和估值区间。
- 能取得图 01 所需的公司股价和合适基准指数历史数据。
- 图 34 的历史估值数据可得时必须生成；确实不可得时记录原因，并用一张有效可选图替代，仍保持至少 25 张。

任一核心输入缺失时停止，指出缺少的文件、工作表或数据；不要用占位数据出图。

## 中文规则

中文用户、A/H 股、中资公司或中文 Vault 场景下：

- 标题、坐标轴、图例、数据标签、脚注、资料来源和图表索引使用中文。
- 使用 PingFang SC、Microsoft YaHei、Source Han Sans、SimHei 或 Noto Sans CJK 等可显示中文的字体，并检查无乱码。
- 单位写在标题或坐标轴中，如收入（亿元）、毛利率（%）、目标价（元/股）。
- 文件名可保留英文，图内文字必须中文可读。

## 工作流

### 1. 核对数据

建立“图号 → 源文件/工作表 → 单位 → 历史/预测口径”映射。读取源文件后检查：

- 历史期与预测期分界明确，预测年份带 `E`。
- 币种、单位、财年/自然年口径一致。
- 图表使用模型真实值，不把示例值、推算占位或截图抄录当数据。
- 派生指标可由源数据复算，例如 FCF、利润率和估值倍数。

### 2. 统一视觉模板

- PNG、白底、300 DPI、宽 6-10 英寸、最小字体 9pt。
- 同类图使用一致颜色、字体、图例位置和数字格式；历史期与预测期有明显区分。
- 标题包含图号和结论性主题；图例、轴标签、单位完整。
- 每张图底部写明具体资料来源和日期；估算值标注“预测/估算”。
- 颜色克制且具备足够对比度，不用 3D、装饰性渐变或无意义双轴。

### 3. 选择图形

- 趋势：折线图。
- 结构变化：堆叠面积图或堆叠柱状图。
- 敏感性：二维热力图，基准情景清楚标出。
- 估值区间：水平区间条/足球场。
- 估值与增长关系：散点或气泡图。
- 价值桥接：瀑布图。
- 竞争定位：2×2 矩阵。

一张图只回答一个主要问题。标签拥挤时缩短文字、旋转标签或改用横向图，不靠缩小字体硬塞。

### 4. 生成并逐张检查

文件名统一为 `chart_[NUMBER]_[description].png`。每张图生成后检查：

- 能打开，尺寸和清晰度正常，没有裁切、重叠、乱码或像素化。
- 标题、图号、轴、图例、单位和资料来源齐全。
- 随机抽取关键点与源表逐项核对；四张强制图全部复核。
- 图 03/04 的分项合计等于总收入；图 28 的基准格等于 DCF 基准目标价；图 32 的区间与估值汇总一致。

### 5. 建索引并打包

创建中文 `chart_index.txt`，每行包含图号、中文标题、文件名、数据源和报告放置章节。将全部图和索引放入同一个 zip；只交付这个 zip，不另建图表清单或完成报告。

Task 4 图号是素材 ID，用于文件名和索引，不等于最终报告图号。Task 5 按正文出现顺序重新连续编号，并保留素材 ID 到报告图号的映射。
