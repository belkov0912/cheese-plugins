# Stock Pulse · 消息面快讯评级

给一只股票测「消息面脉搏」：最新公告利好利空 + 有没有人催票 → 1-10 评级 → 追加到它的笔记。
定位是**快**（秒级看清当下消息面），不是深度研报。深度评分走 [[预期差量化评分标准]] / `expected-gap-score`。

风格：**说人话、结论先行、脱水**。中文金融单位（亿元、万股、美元/股、%）。遵守 `03-Trading/AGENTS.md` 输出政策与 `00-Meta/写作规范/说人话润色规范.md`。

## 铁律（先看这条）

- **每条结论必须带可核验的来源 URL + 日期，不准编造公告、评级或喊单。** 查不到就写「未发现」，不要脑补。
- 快讯块顶部固定写一行：`> 自动聚合信号，非投资建议。以下方来源为准。`
- 不执行任何交易/下单/转账；不接付费数据源、不写任何密钥。
- X / 推特用公开网页和搜索能拿到多少算多少；**够不到就明确标注「X 数据受限」并调低该信号权重**，不要假装抓到了。
- 只追加、不改写：往目标 md 末尾加一段，已有内容一个字都不动。

## 第 1 步：定位目标 md

输入是代码或公司名。在 `03-Trading/个股分析/` 下找对应公司文件夹，目标文件是里面的主笔记 `<公司>/<公司>.md`：

```bash
base="<vault>/03-Trading/个股分析"
ls -d "$base"/*/ | grep -i "<关键词>"        # 按名字/代码模糊找文件夹
# 命中后，目标 = 该文件夹下的 <公司>.md（与文件夹同名的主笔记）
```

- 文件夹存在但没有同名主笔记 → 用文件夹里最像「主入口」的那篇，或新建 `<公司>.md`（带标准 frontmatter，见现有 `AAOI/AAOI.md`）。
- **找不到文件夹、或同名歧义（多只候选）→ 暂停，问用户是哪只 / 要不要新建**，别猜着写。

## 第 2 步：查消息面（联网，24h 优先）

用 WebSearch + WebFetch，分头查这几路，每条记下**日期 + 来源 URL**：

1. **最新公告 / 官方披露**：业绩预告、订单、增减持、回购、定增、诉讼、监管问询、停复牌等。A股看交易所/巨潮/公司公告；美股看 IR / 8-K / PR。
2. **最近 24 小时新闻**：重点。标清每条是 🟢利好 / 🔴利空 / ⚪中性，并写一句话影响。
3. **更早但仍在发酵的关键消息**（最近 1-2 周），简列即可。

判利好利空看：是否超/低于市场预期、是不是一次性、能不能落到业绩、是否已被price in（参考 [[预期差量化评分标准]] 的「催化差」思路：利好是否已出尽）。

## 第 3 步：查催票信号

有没有人在「喊」这只票（这是情绪/资金面信号，不是基本面）：

- **投研机构**：券商/外资给买入·增持评级、上调目标价、发深度报告。
- **网络大 V / KOL**：X、雪球、微博、公众号等公开喊多/拉群/反复提及。
- 每条带出处。**查不到就写「未发现明显催票」**——没有催票本身也是信息（无人关注 ≈ 低位冷门，可能是赔率差的好处）。

## 第 4 步：评级（1-10 利好/利空）

综合消息面 + 催票，给一个分。方向：**分越高越利好**。

| 分 | 含义 |
| --- | --- |
| 1-2 | 极度利空：实锤重大利空（暴雷、退市风险、业绩崩、监管重罚） |
| 3-4 | 偏利空：负面消息为主，或利好出尽转弱 |
| 5 | 中性：没明显消息，或利好利空对冲 |
| 6-7 | 偏利好：有正面催化或机构/大V开始关注，但未到爆发 |
| 8-9 | 强利好：硬利好（爆订单、超预期业绩、政策/客户落地）+ 明显催票共振 |
| 10 | 极度利好：多重硬利好叠加、资金明显进场、催化临近且确定 |

写 1 句话理由。**催票能加情绪分，但不能替代基本面**：只有人喊、没有真消息，最多给到 6，并注明「靠情绪驱动、需验证」。消息稀薄/全靠 X（数据受限）时，明确说明评级置信度低。

## 第 5 步：追加到 md 末尾

把下面这段（填好）**追加**到 `<公司>/<公司>.md` 结尾。多次运行就多段，按时间从上到下累积，便于回看消息面演变。

```markdown

## 📡 消息面快讯 · YYYY-MM-DD HH:MM

> 自动聚合信号，非投资建议。以下方来源为准。

**利好/利空评级：N/10（偏利好/中性/偏利空）** — 一句话理由。

### 最新公告 / 消息（24h 优先）
- 🟢[利好] YYYY-MM-DD 标题 — 一句话影响 — [来源](url)
- 🔴[利空] YYYY-MM-DD 标题 — 一句话影响 — [来源](url)
- ⚪[中性] ...
（最近 24h 无新公告就写：近 24h 无新增公告；并简列最近在发酵的消息）

### 催票信号
- 机构：XX 给「买入」/目标价 XX — YYYY-MM-DD — [来源](url)
- 大V：@XX 喊多 / 反复提及 — [来源](url)
- （没有就写：未发现明显催票）

### 评级依据
- 2-4 条脱水说明，含最大风险 / 最关键验证点。
- X 数据受限时在此注明，并说明对置信度的影响。
```

时间戳用运行当下的真实时间。追加后回报一句：评级 N/10 + 一句话 + 写到了哪个文件。

## 多只批量

用户一次给多只就逐个跑（互相独立可并行查），最后汇总一行，如：`AAOI 7/10 · 铂科新材 5/10 · ST威领 3/10`。
