# prompt-deepen

把一个题目改写成**更深入**而不是**更大**的版本。

## 技能

- **`deepen`** — 重写题目之前，先回答四个问题：
  1. 该领域顶尖专家会做哪些你没要求的事；
  2. 他们会从哪些最原始的素材入手，而不是你整理好的素材；
  3. 他们会用哪些具体的方法和工具；
  4. 除了你和 AI，还有什么能证明结果正确。

  然后输出一段可直接复制的「重写后的题目」。

## 用法

```text
/deepen 分析宁德时代的海外扩张风险
/deepen            # 留空时改写对话里最近的题目
```

只在手动调用时触发（`disable-model-invocation: true`），不会被模型自动加载。
