我想要的是一个**更深入**的版本，而不是一个**更大**的版本。

题目：

$ARGUMENTS

（如果上面为空，就以本次对话中我最近提出的题目或需求为准。）

在重写题目之前，请先依次回答：

1. **专家会多做什么**：该领域的顶尖专家，会做哪些我没有要求的事情？
2. **原始素材**：他们会从哪些最原始的素材入手，而不是我已经整理好的素材？
3. **方法与工具**：他们会使用哪些具体的方法和工具？
4. **外部验证**：除了你我之外，还有什么可以证明结果是正确的？

然后请修改我的题目，使其完全符合上述要求。

输出要求：
- 四个问题逐条回答，具体到可执行，不要泛泛而谈；不要通过扩大范围来"加深"。
- 最后给出一段可直接复制使用的「重写后的题目」。
